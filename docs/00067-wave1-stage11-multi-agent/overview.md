## 术语统一（Stage 11 共用）

- **角色（role）**：一个 Agent 的职责边界 + 工具集 + 输出契约。角色不是人格设定。
- **消息（message）**：角色之间传递的结构化单元，至少含 `from / to / type / payload / traceId`。
- **总线（bus）**：消息的路由层；它**不应该**理解业务语义。
- **监督者（supervisor）**：持有全局计划、分配任务、汇总结果的角色；它的特权是「决定谁做什么」，
  而不是「替谁做」。
- **交接（handoff）**：把控制权连同上下文一起转移给另一个角色。与「调用」的区别是控制权是否回来。
- **收敛（convergence）**：多 Agent 系统停止产生新消息的条件；没有它，群聊模式会无限互评。
