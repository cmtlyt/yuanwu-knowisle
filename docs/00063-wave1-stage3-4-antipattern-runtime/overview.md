## 术语统一（Stage 4 各节共用）

- **一步（step）**：一次「模型决定 → 动作执行 → 观测回填」的完整往复；与「一次模型调用」不是同义词
  （P&E 的一个计划步可能含多次工具调用）。
- **状态（state）**：跨步存活的数据；**轨迹（trace）**：不可变的事件序列。
- **终止（termination）** vs **回归（return）**：停止循环 / 停止后交给调用方的可处理返回值。
- **预算（budget）**：三类受限资源——步数、token、墙钟时间；三者约束的对象不同，不能互相替代。
