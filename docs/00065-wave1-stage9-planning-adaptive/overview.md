## 术语统一（Stage 9 各节共用）

- **子目标（SubGoal）**：带身份、依赖、状态、产出的执行单元；与「步骤（step）」不同——一个子目标
  可能对应多步。
- **计划（plan）**：`SubGoal[]`，是一个可被检查、展示、局部修改的数据对象，而不是 prompt 里的文字。
- **裁决（verdict）**：对一次执行结果的处置，三值——`continue` / `retry` / `replan`。
- **结果账本（ledger）**：以子目标 id 为键的产出表，跨重规划存活；与「轨迹（trace）」不同，
  轨迹是不可变事件序列，账本是可变状态。
- **影响面（impact）**：失败子目标的下游集合，用**比例**而非绝对条数衡量。
- **抽象层级（level）**：执行 / 规划 / 元规划三层，ADaPT 的层级是**逐节点**选定的，不是全局选定。

2. L59 讲清「分解是技巧、分离是结构」的两层问题，给 SubGoal 五个字段各自的来历、Planner / Executor

3. L60 给一套完整可运行的 P&E 引擎：类型层 → 失败分类器 → 结果账本与 `carryOver` → 主循环 →
   mock 跑通 → 事件流 → 三个预算参数的关系。重点是把「失败不等于该重规划」写成代码。
4. L61 把重规划做成一条决策链：先判「执行错 / 计划错 / 目标变」，再算影响面比例定局部或全量，
   并给出震荡的三个成因与「连续同因失败即停」的收敛手段。
5. L62 讲 ADaPT 的递归骨架，用可观测维度替代模型自评难度，讲清与 Least-to-Most 的分工、
   递归深度爆炸的两个上限。
