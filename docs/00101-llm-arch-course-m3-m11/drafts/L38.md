### 从连续状态空间到可递推的离散方程

状态空间模型（SSM）把一个序列建模问题写成一阶线性微分方程：隐状态 $h$ 按 $h'(t)=A h(t)+B x(t)$ 演化，输出 $y(t)=C h(t)+D x(t)$。这里 $x$ 是输入，$h$ 是维度为 $N$（状态维，也叫 d_state）的隐向量，它把「到目前为止读过的全部历史」压缩进一个固定大小的记忆里。$A$ 是 $N\times N$ 的状态转移矩阵，$B$ 是 $N\times 1$ 的输入投影，$C$ 是 $1\times N$ 的输出读取，$D$ 是直连项。要把它放进离散的 token 序列，需要用零阶保持（ZOH）按步长 $\Delta$ 离散化：

$\bar A=\exp(\Delta A),\quad \bar B=(\Delta A)^{-1}\big(\exp(\Delta A)-I\big)\,\Delta B \approx \Delta B$

当 $\Delta$ 很小时 $\bar B$ 近似为 $\Delta B$，于是得到离散递推 $h_t=\bar A h_{t-1}+\bar B x_t$，$y_t=C h_t+D x_t$。这就是 SSM 的状态更新方程：每一步只用上一时刻的 $h_{t-1}$ 与当前 $x_t$ 做一次矩阵-向量乘，状态大小恒为 $N$。下面用一段可跑代码把这套离散化和递推算出来，并直观看 $\Delta$ 改变时 $\bar A$ 如何变。

```python
import numpy as np
np.random.seed(0)
N = 8                          # d_state 状态维
A = -np.abs(np.random.randn(N, N)) / N   # 稳定：特征值实部为负
B = np.random.randn(N, 1)
C = np.random.randn(1, N)
x = np.random.randn(64, 1)     # 长 64 的输入序列

def discretize(A, B, delta):
    Abar = np.linalg.matrix_power(np.eye(N) + delta * A, 1)  # 一阶近似，下面用 expm 精确
    from scipy.linalg import expm
    Abar = expm(delta * A)
    Bbar = np.linalg.solve(delta * A, (Abar - np.eye(N))) @ (delta * B)
    return Abar, Bbar

def scan_ssm(x, Abar, Bbar, C):
    h = np.zeros((N, 1)); ys = []
    for xt in x:
        h = Abar @ h + Bbar @ xt.reshape(1, -1) @ Bbar[:1, :1] if False else Abar @ h + Bbar * xt[0]
        ys.append((C @ h)[0, 0])
    return np.array(ys), h

for delta in (0.01, 0.1, 0.5):
    Abar, Bbar = discretize(A, B, delta)
    ys, h = scan_ssm(x, Abar, Bbar, C)
    print(f"delta={delta:4.2f}  Abar最大特征值模={max(abs(np.linalg.eigvals(Abar))):.3f}  输出范数={np.linalg.norm(ys):.2f}")
# delta 越大 Abar=exp(delta·A) 越小 → 历史衰减越快，输出更依赖当前输入
```

代码里 `delta` 从 0.01 增大到 0.5 时，`Abar` 的最大特征值模显著下降——这正是 $\bar A=\exp(\Delta A)$ 的作用：$\Delta$ 既是「采样步长」，也悄悄控制着记忆衰减速度，这个观察在讲 Mamba 选择性时会变成核心机制。

### S4：结构化状态与卷积视角

经典 SSM 的代表是 S4（Structured State Space）。它有两个关键设计：一是把 $A$ 约束成**结构化矩阵**（对角加低秩，或 HiPPO 矩阵），使 $N$ 可以取到 64 到 256 而矩阵运算仍高效；二是利用 $A$、$B$、$C$、$\Delta$ **与输入无关**这一性质，把递推完全展开成卷积：

$y_t=\sum_{i\le t} C\,\bar A^{\,t-i}\,\bar B\,x_i \;=\;\sum_{i\le t} K_{t-i}\,x_i,\qquad K_j=C\,\bar A^{\,j}\,\bar B$

因为 $K_j$ 只依赖固定的 $\bar A$、$\bar B$、$C$，可以**一次性预计算**整条卷积核，再用快速傅里叶变换（FFT）做卷积，训练复杂度降到 $O(L\log L)$。这就是 S4 比循环神经网络训练快得多的原因：线性时不变（LTI）让「递推」等价于「卷积」，而卷积能被硬件高度并行。

但这个优点同时是枷锁。LTI 意味着无论输入是什么，状态都以同一种方式被写入、遗忘、读出。模型没法说「这个 token 重要，记住它；那个 token 是噪声，忽略它」。在需要**按内容检索**的任务上——比如从前文精确复制一个名字（induction head / 联想召回）——固定卷积核的 SSM 明显弱于能逐 token 定位的注意力。

### 选择性的缺失：LTI 为什么记不住相关内容

用一个具体任务看清问题。假设输入是随机串后面跟着一段「触发词 + 目标 token」，要求模型在下次见到触发词时输出对应的目标 token。全注意力可以直接用 $q$ 去匹配之前那个位置的 $k$，一步定位；而 LTI 的 SSM 只能把目标 token 以固定权重写进状态 $h$，再以固定权重读出，无法「针对当前触发词把特定历史放大」。状态 $h$ 是固定大小的压缩，信息被均匀混合、难以精确取回某一项。这就是纯 SSM 在召回类任务上的短板，也是后面 M4 引入「少量注意力层补召回」（L42）的伏笔。

### Mamba 的选择性：让 Δ、B、C 随输入变化

Mamba（arXiv:2312.00752）的核心改动只有一句话：**让 $\Delta$、$B$、$C$ 由当前输入 $x_t$ 决定**：

$B_t=\mathrm{Linear}_B(x_t),\quad C_t=\mathrm{Linear}_C(x_t),\quad \Delta_t=\mathrm{softplus}\big(\mathrm{Linear}_\Delta(x_t)\big)$

其中 $\mathrm{softplus}(z)=\log(1+e^z)>0$ 保证步长为正。于是离散参数变成时刻相关的 $\bar A_t=\exp(\Delta_t A)$、$\bar B_t\approx\Delta_t B_t$，状态更新改写为：

$h_t=\bar A_t\,h_{t-1}+\bar B_t\,x_t,\qquad y_t=C_t\,h_t$

这里的「选择性」体现在 $\Delta_t$ 的双重作用上：$\Delta_t$ 大时，$\bar A_t=\exp(\Delta_t A)$ 变小（因为 $A$ 特征值为负），旧状态被快速遗忘、当前 $x_t$ 被强烈写入——相当于「打开门，记新忘旧」；$\Delta_t$ 小时 $\bar A_t$ 接近 1，历史几乎原样保留、当前输入写入很弱——相当于「关门，维持记忆」；而 $B_t$、$C_t$ 随内容变化则决定了「写什么」和「读什么」。三者合起来，模型能根据 token 内容动态决定记住还是忽略，这正是 LTI 做不到的事。

代价是：每一步的转移矩阵都不同，无法再预计算统一卷积核 $K_j$。Mamba 的解法是**硬件感知的并行扫描**（associative scan）：把递推看成前缀扫描问题，在 GPU 上并行计算，序列总工作量仍是 $O(L)$、但并行深度降到 $O(\log L)$，训练效率依然很高。下面这段代码对比「固定 $\Delta$」与「输入相关 $\Delta_t$」两种写入强度，直观看到选择性的效果。

```python
import numpy as np
np.random.seed(1)
N, L = 4, 12
A = -0.5 * np.ones(N)
x = np.random.randn(L)

def selectiveHB(x, A, delta_t, B_t, C_t=None):
    """简化标量门控：h_t = exp(delta_t*A)*h_{t-1} + delta_t*B_t*x_t。"""
    h = np.zeros(N)
    writes = []
    for t in range(L):
        h = np.exp(delta_t[t] * A) * h + delta_t[t] * B_t[t] * x[t]
        writes.append(h.copy())
    return np.array(writes)

# 方案一：经典 LTI，delta 固定
d_fixed = 0.3 * np.ones(L); B_fixed = 0.5 * np.ones((L, N))
w_fixed = selectiveHB(x, A, d_fixed, B_fixed)

# 方案二：Mamba 选择性，delta_t 与 B_t 随输入变
d_sel = 0.05 + 0.9 * (x > 0)           # 正 token 大步长→强写入；负 token 小步长→保历史
B_sel = np.tanh(x)[:, None] * B_fixed  # 写入方向随内容翻转
w_sel = selectiveHB(x, A, d_sel, B_sel)

print("固定 Δ 的状态范数序列:", np.round(np.linalg.norm(w_fixed, axis=1), 2))
print("选择 Δ 的状态范数序列:", np.round(np.linalg.norm(w_sel, axis=1), 2))
assert not np.allclose(w_fixed, w_sel), "选择性写入必须与 LTI 写入不同"
print("结论：选择性让状态按内容被写入/保留，而非均匀混合")
```

### 线性复杂度与恒定推理内存

复杂度是 Mamba 最硬的工程卖点。训练阶段，并行扫描把序列维度的计算压到 $O(L)$（S4 是 $O(L\log L)$），而全注意力的自注意力矩阵是 $O(L^2)$，随上下文翻倍、计算量翻四倍。推理阶段差别更 dramatic：Mamba 用递推形式逐 token 生成，**只需保存固定大小的状态** $h$（每个 attention 等价层存 $N\times d$ 个数），内存 $O(1)$、不随已生成长度增长；Transformer 必须保存随长度线性增长的 KV cache，内存 $O(L)$。下面这段把两者的「每 token 内存」算成数量级账。

```python
def state_memory_mb(n_layers, d_state, d_model, n_tokens, bits=16):
    """Mamba：固定状态，与 n_tokens 无关。Transformer：KV cache 随 n_tokens 线性。"""
    mamba = n_layers * d_state * d_model * (bits // 8) / 1e6          # 恒定
    kv = 2 * n_layers * n_tokens * d_model * (bits // 8) / 1e6        # K+V，线性
    return mamba, kv

L_LAYERS, D_STATE, D_MODEL = 32, 16, 4096
for T in (1_000, 8_000, 64_000, 1_000_000):
    mamba, kv = state_memory_mb(L_LAYERS, D_STATE, D_MODEL, T)
    print(f"T={T:>7}  Mamba 状态={mamba:6.1f} MB(恒定)  Transformer KV={kv:8.1f} MB  比值={kv/mamba:7.1f}x")
assert state_memory_mb(L_LAYERS, D_STATE, D_MODEL, 1_000)[0] == state_memory_mb(L_LAYERS, D_STATE, D_MODEL, 1_000_000)[0]
print("断言通过：Mamba 状态内存与序列长无关，Transformer KV 随长度线性增长")
```

数字非常直观：在 32 层、$d_{model}=4096$、$d_{state}=16$ 下，Mamba 的状态只有约 4 MB，且一百万 token 也不变；Transformer 的 KV 在 8K 时已约 4 GB、在 1M 时高达约 500 GB。这就是「恒定推理内存」的实指——长上下文场景里，Mamba 的状态几乎不占地方，把显存全留给权重和计算。

### SSM 与 Transformer 的取舍

把两家摆在一起看待，取舍很清楚。SSM/Mamba 赢在**长上下文效率**：训练线性、推理状态恒定、没有 KV cache 瓶颈，序列越长优势越大；它把历史压进固定状态，天然适合需要「整体理解」而非「逐字取回」的任务。Transformer 赢在**精确召回与表达力**：全注意力让任意两个位置直接交互，联想召回、复制、长距离指代都强，代价是 $O(L^2)$ 训练与 $O(L)$ 推理 KV。M4 后续课程的核心线索就是**把两者拼起来**：用 SSM 承担 long context 主干、用少量全注意力层补召回（L42），并实测这种混合在 KV 与吞吐上的收益（L44）。

### 一句话记住这条主线

S4 的 LTI 让 SSM 能写成固定卷积核、训练飞快，却也让它「对内容盲」；Mamba 用输入相关的 $\Delta/B/C$ 换来选择性，代价是不能预计算卷积核、要靠并行扫描，收获是线性复杂度与恒定推理内存。记住「**固定参数 → 可卷积 → 无选择性**」与「**输入相关参数 → 需扫描 → 有选择性**」这台天平，后面 SSD（L39）、混合架构（L42）、各类线性注意力（L46/L47）全是在这台天平上找平衡点。

:::
