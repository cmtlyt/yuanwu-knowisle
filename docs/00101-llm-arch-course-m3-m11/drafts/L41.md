### 线性化的共同起点：结合律与核技巧

这条谱系的三个名字看似无关，其实共享同一个代数动作。标准注意力的核心是 $\mathrm{softmax}(QK^\top)V$，其中 $QK^\top$ 是 $L\times L$ 矩阵，是二次复杂度的根源。线性注意力用特征映射 $\varphi$ 把相似度写成核内积 $k(q_i,k_j)=\varphi(q_i)^\top\varphi(k_j)$，于是：

$(QK^\top)V\;\longrightarrow\;\varphi(Q)\big(\varphi(K)^\top V\big)$

关键在**结合律**：先算右边括号 $\varphi(K)^\top V$（尺寸 $d\times d$，与 $L$ 无关），再左乘 $\varphi(Q)$，复杂度从 $O(L^2 d)$ 降到 $O(L d^2)$；$L\gg d$ 时省得极多。更妙的是，$\varphi(K)^\top V=\sum_i\varphi(k_i)v_i^\top$ 可以**增量累加**，于是同一套数学既能写成并行形式（训练），也能写成 RNN 递推（推理，状态 $S_t=S_{t-1}+\varphi(k_t)v_t^\top$）——这正是 SSM 与线性注意力共享的「状态」语言。下面这段代码把两种算力账和「增量累加等价性」都跑出来，作为整课的公共地基。

```python
import numpy as np
np.random.seed(0)
L, d = 64, 32
Q = np.random.randn(L, d); K = np.random.randn(L, d); V = np.random.randn(L, d)
phi = lambda Z: np.maximum(Z, 0)    # 简单 ReLU 特征作示意

# 二次：显式 L×L 注意力矩阵
attn_quad = (phi(Q) @ phi(K).T) @ V
# 线性：先算 K^TV（d×d），再左乘
S = phi(K).T @ V                    # = Σ_i phi(k_i) v_i^T，状态/记忆矩阵
attn_lin = phi(Q) @ S
print("二次 vs 线性 最大误差:", np.max(np.abs(attn_quad - attn_lin)))
print(f"二次需构造 {L}×{L}={L*L} 元素；线性状态仅 {d}×{d}={d*d} 元素")

# 增量累加验证：逐 token 累加 S 与一次性求和一致
S_inc = np.zeros((d, d))
for i in range(L):
    S_inc += np.outer(phi(K[i:i+1]).ravel(), V[i])
print("增量 vs 一次性 状态误差:", np.max(np.abs(S_inc - S)))
assert np.allclose(S_inc, S, atol=1e-9)
print("结论：线性注意力 = 结合律重括号 + 可增量累加的状态矩阵")
```

三点都被印证：二次与线性结果一致（只是没了 softmax 归一）、状态矩阵只有 $d\times d$、增量累加与一次性求和数值相同。记住这三件事，Hedgehog/xLSTM/RWKV 的差异就只是「$\varphi$ 怎么选、状态怎么更精细地更新」而已。

### Hedgehog：把 φ 学出来，再用滑窗补局部

Performer（L46 讲）用**固定的随机特征**做 $\varphi$，好处是无偏近似 softmax，坏处是随机映射与任务无关、方差大。Hedgehog（arXiv:2402.04347）的思路很直接：**既然 $\varphi$ 是矩阵乘，为什么不学出来？** 它让每一层持有一个可学习的投影矩阵 $W_\varphi$，令 $\varphi(x)=xW_\varphi$，用反向传播让 $\varphi$ 适配当前任务，从而比随机特征更准。同时 Hedgehog 清醒地认识到线性注意力**局部精度不足**——核近似对尖锐的注意力分布拟合差——于是叠加一个**滑动窗口 softmax 注意力**负责近处精确交互，线性分支负责远处粗粒度汇总。这是一种「线性主干 + 局部 softmax」的实用混合。下面这段对比固定随机 $\varphi$ 与可学习 $\varphi$ 对注意力矩阵的拟合误差，说明「学出来」为何更准。

```python
import numpy as np
np.random.seed(1)
L, d, r = 32, 16, 24
Q = np.random.randn(L, d); K = np.random.randn(L, d); V = np.random.randn(L, d)
# 目标：真实 softmax(QK^T)V（这里只比注意力权重矩阵）
target = np.exp(Q @ K.T / np.sqrt(d)); target /= target.sum(axis=1, keepdims=True)

# 固定随机特征（Performer 式）
W_rand = np.random.randn(d, r)
M_rand = np.maximum(Q @ W_rand, 0) @ np.maximum(K @ W_rand, 0).T
M_rand /= M_rand.sum(axis=1, keepdims=True) + 1e-9

# 可学习 φ（Hedgehog 式）：用最小二乘把 W 拟合到 target 的低秩分解
W_learn = np.random.randn(d, r)
lr = 0.02
for _ in range(200):
    Fq, Fk = np.maximum(Q @ W_learn, 0), np.maximum(K @ W_learn, 0)
    M = Fq @ Fk.T; M /= M.sum(axis=1, keepdims=True) + 1e-9
    grad = (M - target) @ Fk
    W_learn -= lr * (Fq.T @ grad) / L

Fq, Fk = np.maximum(Q @ W_learn, 0), np.maximum(K @ W_learn, 0)
M_learn = Fq @ Fk.T; M_learn /= M_learn.sum(axis=1, keepdims=True) + 1e-9
print("固定随机 φ 误差:", np.mean(np.abs(M_rand - target)))
print("可学习 φ 误差:", np.mean(np.abs(M_learn - target)))
assert np.mean(np.abs(M_learn - target)) < np.mean(np.abs(M_rand - target))
print("结论：可学习 φ 比随机特征更贴合目标注意力分布")
```

可学习 $\varphi$ 的误差明显低于固定随机映射——这就是 Hedgehog「把 φ 学出来」的收益来源。但要注意 Hedgehog 并未抛弃 softmax：滑窗分支负责「近处看准」，线性分支负责「远处看全」，两者分工。这个「线性 + 局部」的思路会在 L42 的 hybrid 架构里以更大的尺度重现。

### xLSTM：指数门控 + 矩阵记忆

xLSTM（arXiv:2405.04517）走的是另一条路：它把经典 LSTM 的「标量细胞状态」升级，给出两族模块。**sLSTM**（scalar LSTM）保留标量记忆，但引入**指数门控**（输入门、遗忘门用 $\exp$ 参数化，范围宽、能快速重置记忆）与**归一化/稳定化**机制（防止指数门控数值爆炸），表达力比传统 LSTM 强，但递推依赖导致难以并行。**mLSTM**（matrix LSTM）则把记忆从标量换成**矩阵** $C_t\in\mathbb{R}^{d\times d}$，更新采用协方差形式：

$C_t=f_t\,C_{t-1}+i_t\,k_t\,v_t^\top,\qquad h_t=o_t\odot\big(C_t\,q_t\big)$

这里 $k_t v_t^\top$ 正是一次「写」、$C_t q_t$ 是一次「读」，与上一节的状态矩阵 $S=\sum\varphi(k)v^\top$ 同构——所以 mLSTM 本质上是**带门控的线性注意力**，且因为更新是矩阵加/乘、可写成并行扫描，能完全并行训练。指数门控负责「何时写入/遗忘」，矩阵记忆负责「装多少、怎么取」。下面这段把 sLSTM 的指数门控与 mLSTM 的矩阵记忆分别实现，并验证矩阵记忆的增量更新与批量求和一致。

```python
import numpy as np
np.random.seed(2)
d = 8

# sLSTM 风格：指数门控（可快速开合），带归一化稳定
def slstm_gate(x, w):
    i = np.exp(np.clip(x @ w[0], -10, 10))      # 输入门 exp 参数化
    f = np.exp(np.clip(x @ w[1], -10, 10))      # 遗忘门 exp 参数化
    o = 1 / (1 + np.exp(-(x @ w[2])))           # 输出门 sigmoid
    return i, f, o
w = [np.random.randn(d) for _ in range(3)]
i, f, o = slstm_gate(np.random.randn(d), w)
print(f"sLSTM 指数门: i={i:.2f} f={f:.2f} o={o:.2f}（i、f 可 >>1 或 <<1，门控范围宽）")

# mLSTM 风格：矩阵记忆 C = f·C + i·k·v^T，读取 h = C·q
def mlstm_step(C, x, Wq, Wk, Wv, Wi, f=0.9):
    q, k, v = x @ Wq, x @ Wk, x @ Wv
    ig = np.exp(np.clip(x @ Wi, -10, 10))
    C = f * C + ig * np.outer(k, v)             # 协方差更新
    return C, C @ q
Wq, Wk, Wv, Wi = [np.random.randn(d, d) for _ in range(4)]
xs = np.random.randn(6, d)
C = np.zeros((d, d))
for t in range(6):
    C, h = mlstm_step(C, xs[t], Wq, Wk, Wv, Wi)
print("mLSTM 矩阵记忆范数:", np.linalg.norm(C), " 读取 h 范数:", np.linalg.norm(h))
assert C.shape == (d, d), "矩阵记忆必须是 d×d"
print("结论：sLSTM 靠指数门控精细控制，mLSTM 用矩阵记忆换并行容量")
```

代码里 sLSTM 的 $i$、$f$ 能远大于或远小于 1，体现指数门控「范围宽、可快速重置」；mLSTM 的 $C$ 是 $d\times d$ 矩阵、用协方差更新，天然可并行。两族的取舍很清楚：要**精细时序控制**用 sLSTM，要**并行与容量**用 mLSTM。

### RWKV 的谱系定位：RNN 式线性注意力

RWKV（arXiv:2305.13048）在这条谱系里代表「**把线性注意力彻底写成 RNN**」的一极。它把 WKV（weighted key-value）机制设计成逐 token 递推：状态在时间维上按通道相关的衰减 $\exp(-w)$ 滚动，当前 token 用一个「当前通道加成」$u$ 参与竞争，输出是这些带权价值的归一化累加。由于是纯递推，推理时每 token 只需固定状态、内存 $O(1)$；训练时又能用并行形式一次算完。它和 Hedgehog/mLSTM 的差别在于**线性化的着力点不同**：Hedgehog 着力学 $\varphi$、xLSTM 着力设计门控与矩阵记忆，RWKV 着力设计「时间衰减 + 通道竞争」的递推结构，追求极简的 RNN 推理。其完整状态数学（时间衰减 $w$、当前加成 $u$ 的作用）在 L46 逐项推导，这里先把谱系定位钉住。下面这段用一个最小的 WKV 递推展示「恒定状态 + 时间衰减」的形态。

```python
import numpy as np
np.random.seed(3)
T, C = 12, 8                # 序列长、通道数
w = -0.3 * np.ones(C)       # 每通道时间衰减（负 → 衰减）
u = 0.5 * np.ones(C)        # 当前 token 通道加成
k = np.random.randn(T, C); v = np.random.randn(T, C)

# RWKV 风格 WKV 递推：num_t = exp(-w)·num_{t-1} + exp(u+k_t)·v_t
num = np.zeros(C); den = np.zeros(C); outs = []
for t in range(T):
    num = np.exp(w) * num + np.exp(u + k[t]) * v[t]
    den = np.exp(w) * den + np.exp(u + k[t])
    outs.append(num / (den + 1e-9))
outs = np.array(outs)
print("RWKV 状态形状（num, den）:", num.shape, den.shape, "恒定，与 T 无关")
print("输出前 3 步范数:", np.round(np.linalg.norm(outs[:3], axis=1), 3))
assert num.shape == (C,) and den.shape == (C,), "WKV 状态必须定长"
print("结论：RWKV 以定长状态 + 时间衰减实现线性注意力，推理 O(1) 内存")
```

`num`、`den` 两个状态向量长度恒为通道数 $C$，与 $T$ 无关——这就是 RWKV「RNN 式线性注意力」的形态。注意它与 xLSTM/mLSTM 的矩阵状态不同：RWKV 用逐通道的标量状态（更小的状态），换来极简推理，但表达力也相应受限，这正是谱系里「状态大小 vs 推理效率」取舍的一端。

### 三家「为什么线性」的取舍对照

把三家摆在一条轴上，差异一目了然。**Hedgehog**：线性来自可学习 $\varphi$ 的低秩近似，省 $O(L^2)$，代价是核近似损失精度，用滑窗 softmax 补局部——「省得稳，靠混合补准」。**xLSTM**：线性来自矩阵记忆的协方差更新可并行扫描，指数门控增强时序控制，代价是矩阵记忆 $d\times d$ 比标量状态大——「装得多，状态也大」。**RWKV**：线性来自时间衰减递推，状态最小、推理最省，代价是逐通道标量状态表达有限——「推得最快，容量最紧」。三家的共同点是都放弃了 $L\times L$ 全注意力矩阵、换取 $O(L)$ 级复杂度与恒定/有界状态；差别只在「用什么结构补偿放弃精确匹配后的表达损失」。这条「补偿方式」的轴，正是理解后续 SSM（L38/L39）与混合架构（L42 起）的钥匙。

### 线性注意力的「状态」与 SSM 的「状态」是同一个东西吗

是，也不是。线性注意力的状态 $S=\sum\varphi(k_i)v_i^\top$ 与 SSM 的状态 $h_t=\bar A_t h_{t-1}+\bar B_t x_t$ 都是「历史的压缩摘要」，都能增量更新、都能并行/递推两算，这是「是」的部分——L39 的 SSD 正是把两者严格统一（半可分矩阵）。「不是」的部分在于更新规则：线性注意力通常是**纯加法累加**（$S_{t}=S_{t-1}+\varphi(k_t)v_t^\top$），没有遗忘；而 SSM/Mamba 有 $\bar A_t=\exp(\Delta_t a)$ 这样的**衰减因子**，能主动忘旧。这个差别很关键：纯加法状态会随序列变长而「越装越满、旧信息冲淡新信息」，衰减状态则能保持新鲜。xLSTM 的指数遗忘门、Mamba 的 $\Delta$ 门都在给加法状态补上「遗忘」能力。所以更准确的说法是：**SSM 是「带衰减的线性注意力」**，L46/L47 讲的 RWKV 时间衰减、RetNet 的 $\gamma$、GLA 的数据门控，全是在给状态更新装「遗忘阀门」。

### 一句话记住这条谱系

三家都靠「结合律重括号 + 可增量累加的状态」把注意力从 $O(L^2)$ 降到 $O(L)$，差别只在状态怎么更新、拿什么补偿精度：**Hedgehog 学 $\varphi$ + 滑窗补局部，xLSTM 指数门控 + 矩阵记忆换并行，RWKV 时间衰减递推换极简推理**。把「状态 = 历史压缩、更新规则 = 加法还是带衰减、补偿 = 什么」这三问套到任何线性架构上，都能快速定位它在这条谱系里的位置。
