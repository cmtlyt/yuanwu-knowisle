### 从纯 SFT 的天花板说起

上一课 L89 把指令微调的「示范学习」走完，但纯 SFT 有个结构性短板：它只在「专家写过的回答」上做 next-token 监督，模型学到的上限被示范数据的质量与覆盖面锁死。对同一个 prompt，人类其实能区分「更好」和「更差」的多个回答，这种**相对偏好**里藏着 SFT 的交叉熵损失拿不到的信号。RLHF（Reinforcement Learning from Human Feedback）就是把这类偏好信号接进优化目标。InstructGPT（arXiv:2203.02155）给出的标准流程是三段：**SFT 暖启动 → RM 奖励建模 → PPO 强化学习**，并在最后一段用 KL 惩罚把策略拴住。

:::deep

### 为什么不能直接拿人类打分做监督

直接让标注员给每个回答打 1 到 10 分，再当回归目标训练，听起来最直接，实际不可行：不同标注员的尺度不一致（有人给 7 分相当于别人的 5 分），同一个人前后也不一致。改成**成对比较**就稳定得多——判断「A 比 B 好」比「A 打几分」主观方差小得多。RM 训练因此建立在偏好对上，用 Bradley-Terry 模型把「偏好」转成可微的标量差：P(c > r) = sigmoid(r_c − r_r)。这条从「绝对分」到「相对偏好」的转换，是 RLHF 能用起来的第一块基石。

:::

### 阶段一：SFT 提供起点与参考策略

第一阶段用人工撰写的高质量 (prompt, response) 对做监督微调，得到一个初步会「听指令」的策略 π_SFT。它有两个身份：**PPO 的初始化策略**，以及后续 KL 惩罚里的**参考策略 π_ref**。参考策略这个角色很关键——KL 惩罚衡量的是「当前策略偏离起点多远」，没有这个锚点，约束就无从谈起。SFT 阶段不需要多复杂，目标是让模型进入「能产出合理回答、偏好对里 chosen 与 rejected 都有非零概率」的分布，否则后续探索全是噪声。

### 阶段二：RM 把偏好对变成标量奖励

第二阶段训练奖励模型 r_θ(prompt, response) → 标量。对每个 prompt 采样若干回答，让标注员排序，拆成多个 (chosen, rejected) 对。训练损失是 Bradley-Terry 的负对数似然：L = −log σ(r_c − r_r) = softplus(r_r − r_c)。下面这段可跑代码把损失算出来，并验证「偏好差距越大、损失越小」这一核心性质。

```python
import math

def bradley_terry_loss(r_chosen, r_rejected):
    # P(chosen > rejected) = sigmoid(Δ)，Δ = r_c - r_r
    # 损失 = -log sigmoid(Δ) = softplus(-Δ) = log(1 + exp(-Δ))
    delta = r_chosen - r_rejected
    return math.log(1 + math.exp(-delta))

pairs = [(1.2, 0.3), (0.8, 0.7), (2.0, -0.5)]
losses = [bradley_terry_loss(c, r) for c, r in pairs]
print("逐对损失:", [round(x, 4) for x in losses])
print("平均损失:", round(sum(losses) / len(losses), 4))
assert all(x > 0 for x in losses), "偏好对损失必须为正"
assert losses[2] < losses[1] < losses[0], "奖励差越大，损失应越小"
```

输出里 third pair 奖励差 2.5、损失仅约 0.08，而 second pair 差 0.1、损失约 0.64——RM 被训练成「尽量把人类偏好的回答往上推」。需注意 RM 只在**训练分布附近**可信：PPO 后策略会产出 SFT 阶段没见过的回答，这些分布外样本上 RM 容易给虚高分，这正是阶段三要用 KL 拴住分布的原因。

### 阶段三：PPO + KL 惩罚，在约束中爬升

第三阶段把 RM 当奖励函数，用 PPO 优化策略。每一步的逐 token 奖励写成：r = r_θ(prompt, response) − β · KL(π ‖ π_ref)。其中 r_θ 只在整条回答末尾给一次（稀疏奖励），KL 惩罚按每个生成 token 累加（稠密约束）。β 是 KL 系数：β 太大策略几乎不动、对齐无效；β 太小则策略迅速偏离参考分布去骗 RM 的高分（Reward Hacking），表现为输出重复、谄媚或乱码。下面用一个 4 词小词表把 KL 惩罚的数值效应算清楚。

```python
import math

def kl_divergence(pi, ref):
    assert abs(sum(pi) - 1) < 1e-9 and abs(sum(ref) - 1) < 1e-9
    return sum(p * math.log(p / r) for p, r in zip(pi, ref))

ref = [0.10, 0.20, 0.30, 0.40]
beta = 0.02
for label, pi in [
    ("未漂移", ref[:]),
    ("略漂移", [0.12, 0.22, 0.30, 0.36]),
    ("大漂移", [0.40, 0.30, 0.20, 0.10]),
]:
    kl = kl_divergence(pi, ref)
    reward = 1.0 - beta * kl
    print(f"{label}: KL={kl:.4f}  净奖励≈{reward:.4f}  KL罚分≈{beta*kl:.4f}")
assert kl_divergence(ref, ref) == 0.0, "相同分布 KL 应为 0"
assert kl_divergence([0.40,0.30,0.20,0.10], ref) > kl_divergence([0.12,0.22,0.30,0.36], ref)
```

「大漂移」那行 KL 约 0.46、罚分约 0.009，把 RM 给的 1.0 奖励明显拉低——这就是约束在数值上的样子。PPO 另有一层「近端」约束（裁剪概率比 ε），限制**单步**更新幅度；KL 惩罚约束的是**整段训练后相对参考策略的累计漂移**，两者一短一长，配合起来才稳。

**1.3B 胜 175B：对齐收益可以超过规模**

InstructGPT 论文里最反直觉的结论：经 RLHF 对齐的 1.3B 参数模型，在人类偏好评测中的输出**优于**未对齐的 175B GPT-3。这不是说 1.3B 的知识量更大，而是说「按人类偏好排序的输出质量」与「模型规模」不是同一条轴——一个被对齐的小模型在「有用、诚实、无害」的行为维度上，可以压过一个只会续写文本的大模型。这条结论奠定了整个后训练/对齐模块的意义：对齐不是锦上添花，而是把已有能力「兑现」成用户真正想要的行为，其收益在某些评测维度上超过再堆一个数量级的参数。

:::tip

### 一段话记住三阶段

SFT 给你**起点和锚点**（π_ref），RM 把**相对偏好**压成标量，PPO 在 RM 指引下爬升、用 KL 惩罚**拴住不跑偏**。三者的分工是「暖启动 → 学奖励 → 带约束地优化」。下一课 L97 讨论副作用：对齐会把通用基准分数拉低（对齐税），以及 PPO-ptx 如何用预训练梯度把这部分补回来。

:::

**工程判据：什么时候 RLHF 会翻车**

把三阶段的失败模式落成可自查的清单：① **SFT 没做好**——chosen/rejected 在初始策略下概率都接近 0，RM 学不到有效差值，PPO 探索全噪声；② **RM 过拟合**——偏好对不够多或与评测分布不符，RM 在分布外给虚高分；③ **KL 系数失当**——β 过大对齐无效、过小奖励作弊；④ **奖励长度偏置**——RM 倾向给长回答高分，PPO 学会灌水。这四条里任何一条中招，表现都是「训练曲线好看、人工评测却变差」，判据永远是**拿独立的人评或基准验证**，而不是只看 RM 分数上升。M10 后续的 DPO（L98）、GRPO（L99）都在尝试绕开这套复杂度，但 KL 约束与分布漂移的基本矛盾始终存在。
