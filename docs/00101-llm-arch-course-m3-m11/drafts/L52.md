### 连续 score matching 为什么搬不到离散 token

连续扩散（DDPM、score-based 模型）的核心是对数据分布加高斯噪声，再训练一个网络预测 score，也就是 log 密度的梯度 s(x) 等于 ∇_x log p_t(x)。训练目标是 Fisher divergence：让网络输出的 score 逼近真实 score，即 E 范数平方（s_θ(x) 减 ∇log p_t(x)）。这套机制依赖一个前提：数据 x 是连续向量，能对 x 求梯度。语言 token 偏偏是离散符号——「苹果」这个词没有「梯度方向」，你不能把它往某个方向推一点点。若强行把 token one-hot 当连续向量求梯度，得到的方向会立刻跑出单纯形，失去离散意义。所以 L49 的掩码扩散走了一条务实路线（直接预测被掩 token），而 SEDD（Score Entropy Discrete Diffusion，arXiv:2310.16834，ICML 2024 Oral）则要做一件更理论化的事：**在离散状态空间上重新定义一个等价的 score 与训练目标**，让 score matching 的真正威力（尤其是可控采样）在离散域也能兑现。

### score entropy：用对数速率比替代梯度

SEDD 的第一步是把前向过程写成连续时间马尔可夫链（CTMC）。离散状态随时间以某个速率（rate）互相转移，用一个 rate matrix R_t 描述：R_t(x, y) 表示 t 时刻从状态 x 跳到 y 的速率。为简化，SEDD 取与掩码扩散一致的吸收态结构（token 可跳到 [MASK]）。关键创新在 score 的定义：既然没有梯度，就用**状态间的对数速率比**代替——s_θ(x)_y 近似 log（q_t(y) 除以 q_t(x)），即「从当前状态 x 恢复成状态 y 的相对倾向」。反向过程的速率则由 exp(s_θ(x)_y) 给出，取指数保证了速率非负（这是概率转移的硬约束）。训练损失叫 **score entropy**，它是连续 Fisher divergence 在离散域的 analog：对每个状态 x 和每个可转移的 y，惩罚模型给出的 score 与前向速率隐含的真实 score 之间的差距，形式上有 exp(s_θ(y)_x) 这样的项来平衡正反方向。直观理解：score 告诉你「这个被掩位置该填什么、倾向多强」，score entropy 就是让这个判断在每个时刻、每个位置都尽量准。

:::deep

### 为什么 score entropy 比「直接预测 token」更强

L49 的掩码扩散把反向目标简化成「预测被掩位置的原 token」，这是个交叉熵分类目标，简单好用。SEDD 的 score entropy 看似绕了一圈，优势在哪？第一，**统一的连续时间框架**：CTMC 让前向/反向都有清晰的数学结构，采样时可对不同时刻用不同步长的求解器，而不像离散步数那样被钉死——这是后面「32× 更少评估」的数学基础。第二，**score 携带方向信息**：score 不只是「最可能是哪个 token」，而是「每个候选 token 的相对速率」，这让采样可以用更复杂的引导（guidance）、并自然支持条件化（infilling）。第三，**理论保证**：score entropy 与数据分布的交叉熵有等价关系，优化它有原理上的合理性，不是纯启发式。代价是形式更复杂、实现更讲究（速率矩阵、指数数值稳定性），这也是它不如掩码扩散直观的原因。一句话：掩码扩散是「够用的简化」，SEDD 是「保留理论威力的完整版」。

:::

### 可跑代码：score entropy 与采样步数账

下面用纯 Python 把 score entropy 的核心计算跑出来（小词表、手算速率），并模拟采样评估数的收益。

```python
import numpy as np

# 4 个 token 的小词表：0=苹果 1=香蕉 2=橘子 3=[MASK]
V = 4
rng = np.random.default_rng(0)
# 前向 rate matrix：每 token 以 rate=beta 跳到 [MASK]（吸收态）
beta = 0.1
R = np.zeros((V, V))
for i in range(V - 1):
    R[i, 3] = beta          # 普通 token → [MASK]
R[3, 3] = 0.0               # 吸收态不再跳出

def score_entropy(s, r_t, eps=1e-8):
    """score entropy 核心项：对每对 (x,y)，r(x,y)·[s(x)_y - exp(s(y)_x)]。
    取 exp 保证反向速率非负；这里做最小化，故写成该形式。"""
    loss = 0.0
    for x in range(V):
        for y in range(V):
            if x != y and r_t[x, y] > 0:
                loss += r_t[x, y] * (s[x, y] - np.exp(s[y, x]) + eps)
    return loss

s = rng.normal(0, 0.5, (V, V))   # 模型输出的 score（对数速率比）
L = score_entropy(s, R)
print(f"score entropy 初值={L:.3f}（训练会把 s 推向真实速率比，使 L 下降）")

# 校验：反向速率 exp(s) 必非负
assert np.all(np.exp(s) > 0), "exp(score) 必须给出非负速率"
print("exp(score) 非负断言通过")
```

```python
def eval_budget(base_evals, speedup):
    """SEDD 的「计算换质量」：约 32× 更少评估达到同等质量。"""
    return base_evals / speedup

base = 1024          # 基线为达某困惑度所需的网络评估数
sedd = eval_budget(base, speedup=32)
print(f"基线评估数={base}，SEDD 约 32× 更少 → {sedd:.0f} 次评估达同等质量")
assert sedd <= base / 20, "SEDD 应显著减少所需评估数（论文量级约 32×）"
# 注意：这里是「同等质量所需评估」减少，不是把采样变成单步
```

第一段把 score entropy 的计算形式（含 exp 非负约束）落成可跑代码，`score_entropy` 里的 `r_t[x,y]·[s[x,y] - exp(s[y,x])]` 就是离散版 Fisher divergence 的核心项。第二段把「32× 更少评估」写成可核对的量：基线要 1024 次网络评估达到某困惑度，SEDD 约 32 倍更少（约 32 次）就够——注意口径是「达同等质量的评估数」，不是「采样变成单步」，这是最容易被误读的点。

### 同规模 ppl 降 25–75% 怎么读

SEDD 论文（ICML 2024 Oral，A 级数字）报告：在相同参数规模下，困惑度（perplexity，ppl）相比自回归模型降低约 25% 到 75%。ppl 是衡量语言建模质量的经典指标，越低表示模型对真实文本的分布拟合越好。这条结果的意义在于，它说明离散扩散的目标函数**本身**有质量潜力——不是靠堆参数或堆数据赢，而是「同样的模型大小，换个训练目标就更好」。但读这个数字要带三点清醒：第一，ppl 是语言建模指标，不等同于下游任务准确率，别把「ppl 降 75%」直接说成「所有任务强 75%」；第二，25% 到 75% 是个区间，跨模型规模与数据集波动大，选型时要看**你自己任务上**的实测；第三，质量优势要连同代价一起看——SEDD 的采样仍要多步迭代，质量收益不等于免费午餐。

### 计算换质量：32× 更少评估的 trade-off

「计算换质量」在 SEDD 里有个具体含义：它的反向 CTMC 求解器效率高，论文报告约 **32 倍更少的网络评估**就能达到基线（如早期离散扩散方法）用更多步才有的质量。换个说法，在固定评估预算下，SEDD 能把省下的计算再投进去（用更好的求解器、更多采样步细化），换来更高质量；在固定质量目标下，它需要的计算更少。这是一种双向可用的 trade-off，核心是 CTMC 框架允许「连续时间、自适应步长」的采样，而非像掩码扩散那样被离散步数绑死。工程上这意味着：SEDD 给你一根比掩码扩散更细的旋钮——想要快，就少评估、接受质量略降；想要好，就多评估、把质量拉满。这正好呼应 L53 的 Dream「质量-速度可调」，是扩散家族共同的工程优势。

### 可控 infilling：score 天然支持条件生成

SEDD 做 infilling 比自回归自然得多。自回归要填句中某段，必须先生成前缀、再在约束下续写、还要保证后缀匹配，本质是「被顺序绑住」。SEDD 的 score 定义了**任意被掩状态**的恢复方向，所以 infilling 只需两步：把已知位置固定（不参与去噪）、把目标位置设为 [MASK]，然后用同一套 score entropy 训练出的模型对目标位去噪填充。已知位置的 token 通过双向注意力被模型看到，成为填充的上下文；score 给出每个候选 token 的相对速率，采样时按它选择。整个过程不需要重新训练、不需要改模型结构，只是把「哪些位置被掩」这个输入条件换一下。这就是「可控生成」在扩散框架里的本质：**控制掩码的位置，就控制了生成的位置**。L54 会把 infilling、fill-in-the-middle、约束生成做成可跑的冒烟对比。

:::tip

### 收束：掩码扩散是简化版，SEDD 是完整版

L49 的掩码扩散把反向目标简化成预测被掩 token，够用、直观；SEDD 用 **score entropy + rate matrix + 对数速率比**把 score matching 完整搬到离散域，换来三件事：同规模 ppl 降约 25% 到 75% 的质量潜力、约 32× 更少评估的计算效率、以及天然的可控 infilling。记住 trade-off 的口径——「更少评估达同等质量」，不是免除多步去噪。带着这套理论，L53 看 Dream 如何用 AR 初始化把扩散收敛做快，L54 把 infilling 做成实操工具。

:::
