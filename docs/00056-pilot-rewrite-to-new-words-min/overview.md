# 00056 · 按 00055 新字数下限重写 Wave 0 试点六课

## 目标

00055 把体量闸门的正文字数下限抬到 1200 / 1800 / 1500 / 1800 / 3000（overview 400）后，Wave 0 六节试点课只剩 L26 擦线达标（1207/1200），其余五节缺口 441–1115 字。本任务按新下限把这六节补齐，同时保持 00052 定下的三元标准（理论 + 代码 + 经验）与各自课型模板。

补的不是字数，是**原来缺失的那部分内容**：每节新增的段落都要能独立回答一个问题（机制边界、失败模式、工程取舍），不允许用复述、排比、同义改写凑量。
