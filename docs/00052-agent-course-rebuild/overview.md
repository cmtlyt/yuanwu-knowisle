# 00052 · Agent 课程重构（理论 + 代码 + 经验三元，按课型分化）

## 状态

规划中（**未实施**）。基于 00051 落地的课程数据做质量评估后提出；用户要求「先出方案、暂不改动课程正文」。本目录目前只承载规划基线，待用户批准 Wave 0 试点后再进入实施。

## 目标

把 00051 落地的 142 节 Agent 课，从「单一概念介绍骨架」重构为「**理论 + 代码 + 经验**」三元精品课：

- 每课同时具备：理论（机制 / 为什么 / 边界）+ 代码（可跑 / 可验证、递进多片段）+ 经验（真实踩坑：失败现象 → 检测 → 修复 → 反例）。
- 按 4 种课型（A 理论 / B 实战 / C 框架对照 / D 专项 + Capstone）分化模板，打破 142 课同构。
- 测验从「纯回忆」升级为「回忆 + 应用 + 改错 + 设计」混合，提升布鲁姆层级。

## 变更计划

### 0. 评估证据（为什么需要重构）

对 `app/data/agent-course/lessons/` 全量统计（2026-11-15）：

| 维度 | 现状 | 结论 |
|---|---|---|
| 单课行数 | 142 课 **100% < 100 行**（min 70 / max 95 / 中位 76） | 容不下三层内容 |
| 内容块数 | 100% 恰好 **5 块**（1 prose + 1 code + 2 callout + 1 list） | 与课型无关，范式课 ≈ Capstone 课 |
| 代码块 | 99% 仅 1 个；其中 **53% 以 `// ①` 注释 / 示意图起头** | 多为示意片段，少递进、无可跑 |
| 测验 | 100% 是「3 选 1 单选」，正确项 = 正文原话改写 | 零应用层，记忆回溯 |
| 专项 / Capstone（L116–L142） | 多为 ASCII 架构图 + 清单，无真实实现 | 「实战」承诺落空 |

**根因**：用同一套「概念介绍骨架」复制 142 次，结构不随主题深浅变化 —— 这正是「每节都只是概念介绍」的结构性根源，而非个别课水。

**保留项（不重做）**：概念 DAG / `prereqs` / `Lxx` 互引（架构正确）；pitfalls 思路（升级为经验块）；模块 / 阶段 / 子阶段；complex 渲染层。重构保持课时 `id` 与概念 `id` 不变，图谱与引用完整性不受影响。

### 1. 精品课三元标准（每课必备）

- **理论**：机制 + 为什么 + 何时用 / 何时不用（prose + deep callout + 对比表）。
- **代码**：可跑 / 可验证，不止一个、递进（直觉 → 严谨 → 边界）；实战课给完整函数 + `// 运行:` 注释。
- **经验**：独立「实战经验」块 = 失败场景 + 现象 + 检测 + 修复 + 代码反例（现有 `warn` callout 升级，配反例片段）。

### 2. 四课型新模板（体量 + 结构，打破同构）

| 课型 | 覆盖阶段 | 目标体量 | 结构要点 |
|---|---|---|---|
| **A 理论 / 范式** | 2、8、10 | ~150–220 行 / 8–10 块 | 动机 → 机制（伪代码）→ **相邻范式对比表** → 适用 / 不适用 → 经验 → 2 应用题 |
| **B 实战 / 实现** | 4–9、11–15 | ~250–400 行 / 12–16 块 | 需求 → 接口 → **逐步实现（代码 ↔ 解释交替 3–5 步）** → 跑通验证 → 边界 → 经验 → 含改错题 |
| **C 框架对照** | 16–21 | ~200–300 行 | 手写回顾 → 框架等价代码 → **差异对照表（代码量 / 可控性 / 锁粒度）** → 何时选 / 何时退 → 经验 |
| **D 专项 / Capstone** | 23–27 | 专项 ~200–300 / Capstone ~300–500 行 | 场景 → 架构 → **关键模块真实实现（不止图）** → 端到端片段 → 评测 / 安全 / 成本切面 → 生产踩坑 |

### 3. 测验重构（混合层级）

每课 **4–5 题**：1 回忆 + 2 应用（给场景选范式 / 补全代码）+ 1 改错（给有 bug 片段定位）+ 1 设计 / 开放。

→ 需先评估是否扩展 `q()` 数据模型以支持「代码 / 改错题」题型（现有 `q(text, options[], idx, explain, concept)` 仅 MCQ；引入新题型需同步改渲染层）。

### 4. 实施节奏（先试点对齐，再分批）

- **Wave 0 试点（6 节，覆盖 4 课型）**：L26（理论）/ L42（实战）/ L96（框架）/ L116（专项）/ L128 + L135（Capstone），按新标准重做供用户审质量基线。
- **Wave 1**：核心运行时（阶段 4–9，~40 课）实战化。
- **Wave 2**：范式 + 推理 + 多智能体（阶段 2、8–11，~40 课）。
- **Wave 3**：框架 + 专项 + Capstone（阶段 16–27，~60 课）。
- 每 Wave 后跑 `verify-course` + lint + typecheck + build 回归。
