## 三节各补了什么

- **L23**：给了「自主」的算术上限——单步 95%、20 步串联只剩 36%，这一条比任何价值判断都更能解释
  2023→2024 的行业转向；把「自主拆解 / 自主调度 / 自主执行」拆成三个可分别取舍的维度；补了带预算、
  验收条件、人工闸门的循环实现，并指出「验收通过就不派生」是全改动里收益最大的一行。
- **L24**：把 LtM 与普通分治的区别落在「难度阶梯 vs 同难度切片」和「后一问复用前一问的解法做示范」；
  把 ADaPT 的贡献落在「用客观执行失败代替难度预估」；补了四方法定位表（CoT / P&E / LtM / ADaPT）
  与「拆分收益 > 转述损耗」的判断不等式。
- **L25**：讲清有效性来自「正确收敛、错误发散」的统计结构，以及它失效的唯一方式（错误也集中）；
  补了归一化这一真正的工程量、k 的边际收益曲线、以及「SC 花钱买稳定但不买延迟」与 ToT/LATS 的
  成本结构差异（决定了实时请求用 SC、离线批处理用 LATS）。

## 附带发现：容器内块级内容被压平

写 L25 时把一张四方法对照表放进了 `:::deep`，端到端抽查发现表格退化成一行竖线。根因在
`app/lib/markdown.ts` 的 `callout_open` 渲染规则：正文用 `renderInline` 输出，容器内的**表格 / 列表 /
多段落 / 代码块全部被压成一段行内文本**。已改为块级渲染并补 callout 内排版样式，详见
`docs/00062-callout-block-content/`。
