## 3. 架构事实（F-A*）

- **F-A1｜六套 Harness 架构对照（C，S11，须交叉验证）**：Claude Code = 单线程主循环 + 模块化服务，`while(true)` 六步流水线，只读工具并发 / 写状态工具串行，权限检查位于 PreToolUse hook 与规则引擎之间，接近窗口上限自动压缩（先清旧工具输出再摘要对话）；OpenCode = **状态机 + Runner**；Codex = Thread 内 **Turn loop**；DSH = 可替换插件的 **ReactLoopAgent**；Pi = **扁平 while + 25 个 hook**、仅 **4 个工具**、系统提示 **<1000 token**；Hermes = **TAOR + 状态机**的自进化闭环。四个同构旋钮：权限放哪层（Claude Code 六层权限 + AST 分类器；Pi 不做权限系统，安全责任交还用户）、压缩触发点（Claude Code 窗口减 **13K**、Codex 窗口 **90%**、Pi 输入预算 **50%**）、循环何时结束（模型自判 / 最大步数 / 外部状态机）、人能否中途插话。该文主张 `Agent = LLM + Harness`。
- **F-A2｜Claude Code 官方机制（A，S19/S17/S18/S16）**：七种指令载体 —— `CLAUDE.md`、rules、skills、subagents、hooks、output styles、追加 system prompt，差异在「何时进上下文 / 压缩后是否留存 / 权威性」。根 `CLAUDE.md` 会话开始即载入且整个会话常在上下文中（memoized，压缩后清缓存重读，成本高）；子目录 `CLAUDE.md` 按需、压缩后丢失直到再次触碰该目录；rules 在压缩时重注入；skills 仅名称+描述常驻、被调用才载入全文并共享 token 预算（最旧的先淘汰）；subagents 只回传最终消息。hooks 生命周期覆盖 `PreToolUse`（可阻断）、`PermissionRequest`、`PermissionDenied`（可用 `retry: true` 允许模型重试）、`PostToolUse`、`PostToolUseFailure`、`PostToolBatch`、`SubagentStart/Stop`、`TaskCreated/Completed`、`Stop`、`PreCompact`、`ConfigChange`、`CwdChanged`、`FileChanged`、`WorktreeCreate/Remove` 等。Agent SDK 支持 `permission_mode="acceptEdits"`、`HookMatcher(matcher="Edit|Write", ...)`、`AgentDefinition` 自定义子代理并需在 `allowed_tools` 里含 `Agent`。
- **F-A3｜Codex CLI 官方机制（A，S20/S21/S22）**：`AGENTS.md` 是开放格式（官网称 6 万+ 开源项目采用），与 README 分工明确。官方最佳实践把 prompt 拆成四要素：**Goal / Context / Constraints / Done when**，并建议用 `@` 引用文件。权限由两个正交维度构成：`approval_policy`（何时询问）与 `sandbox`（不可信命令的执行策略）。搜索结果给出的是**多个 fork 镜像 README**（`ReleasedGroup/codex`、`ivanevtillms/codex`、`Thejo36/codex`），内容一致但**不是官方仓库**，须抓 `github.com/openai/codex` 核对：旧口径 `--approval-mode` 四档 Suggest（默认，只读自由 / 写与任意 shell 需批准）、Auto Edit（可 apply-patch 写 / shell 仍需批准）、Full Auto（读写 + shell，断网且写入限 cwd）、Unsafe（无提示无沙箱）；新口径 `--ask-for-approval untrusted|on-failure|never` × `--sandbox read-only|workspace-write|danger-full-access`；`--full-auto` = on-failure + workspace-write，失败退出码才请求批准并在沙箱外重试。平台沙箱：macOS 12+ 用 Apple Seatbelt `sandbox-exec -p`，Linux 用 Landlock/seccomp；容器内若宿主不支持则建议容器自身提供保证。非 Git 目录进入 auto-edit/full-auto 会有警告。
- **F-A4｜OpenCode 官方机制（A，S14/S15）**：MIT、由 Anomaly 主导，官网自述 226,557 GitHub stars / 1,000+ 贡献者 / 22M 月活开发者（**官网自述、快照数字**）；支持 MCP servers、plugins、skills，以及 ChatGPT Plus/Pro、GitHub Copilot 登录或订阅。权限是三态 `allow` / `ask` / `deny`；**v1.1.1 起旧布尔 `tools` 配置废弃并合并进 `permission`**（保留兼容）；支持全局 `"*": "ask"` 后按工具覆盖，也支持对象语法按输入模式细分（如 `"bash": {"*": "ask", "git *": "allow", "rm *": "deny"}`、`edit` 按路径 glob），通配符 `*` / `?`，**最后匹配的规则优先**（故通用规则写前面）；`~` / `$HOME` 展开用于 `external_directory`；`opencode --auto` / `opencode run --auto` 自动批准未被显式 deny 的请求，TUI 里也可切换，显式 deny 仍生效。
- **F-A5｜Pi 官方机制（A，S12；C 补充 S38/S39）**：15+ providers / 数百模型，API key 或 OAuth，会话中用 `/model` 或 Ctrl+L 换模型、Ctrl+P 轮换收藏；**会话存成树**，`/tree` 回到任意历史点继续，所有分支在单一文件里，可加书签、按消息类型过滤、`/export` 导出 HTML、`/share` 传 gist 得到可渲染链接。上下文工程：`AGENTS.md`（从 `~/.pi/agent/`、父目录、当前目录启动时加载）、`SYSTEM.md`（按项目替换或追加默认系统提示）、Compaction（接近上下文上限自动摘要旧消息，**可由扩展完全替换**：主题式压缩、代码感知摘要、换摘要模型）、Skills（指令+工具的能力包，按需加载、渐进披露且不破坏 prompt cache）、Prompt templates、`/name` 展开、扩展可在每轮前注入消息 / 过滤历史 / 做 RAG / 长期记忆。**Steering vs Follow-up**：运行中直接 Enter 发 steering message（当前工具执行后送达，并中断排队中的剩余工具），Alt+Enter 发 follow-up（等当前轮结束）。第三方补充（C）：作者 Mario Zechner（badlogic，libGDX 作者），2025-08 首发 `pi-mono` monorepo，MIT，npm 包 `@earendil-works/pi-coding-agent`，五个包 `pi-ai` / `pi-agent-core` / `pi-coding-agent` / `pi-tui` / `pi-web-ui`；刻意不做 subagents、plan mode、permission popups、MCP，一切交给 TypeScript Extensions + Skills。
- **F-A6｜DSH 官方/架构文档机制（A/B，S23/S24/S25；C 细化 S34/S35/S36）**：README 第一句 `Everything is a plugin`；底层 **Cordis** 插件内核（可逆副作用：插件注册的能力在卸载时自动回收，故可热插拔、「不存在需要打补丁的特权内核」）；模型适配器、工具注册表、会话日志、沙箱、审批策略、子代理、调度器，乃至 agent loop 与 UI 都是插件。启动时**四层配置**按优先级叠加：profile 里的 bundles → profile 的 `cordis.patch.yml` → 主目录 patch → 命令行 `--patch`；`dsh --profile web --dump-config` 可自省整棵插件树，任意一行都能被 patch 覆盖。自带 profile：`web` / `headless` / `sdk` / `sdk-minimal` / `acp`，前四者共享 `dsh-base`（适配器、工具、持久化、沙箱与审批、设置、凭据、遥测），`sdk-minimal` 是刻意不套 base 的例外。**四种模式**：Standard（全套工具，默认）、PTC / Code（模型写一段代码把多轮工具调用组合起来，中间数据留在执行环境，省 token）、Minimal（只留 1 个 shell + 1 个文件编辑工具，用来测模型底色 / 做最小环境基准）、Creative / Creator（在内存里试插件、组合新模式）。一轮 `turn` = 0..n 个 `step`，一步 = 一次模型请求 + 它调起的工具；工具走 **pre-execute（校验拦截）→ execute → post-execute（结果加工）** 三段管线；turn 的边界是「从认领第一条输入开始，到没有任何欠账为止」，有欠账就回到 `step/start`。会话日志是 **append-only 事件流**（系统提示、思考、工具调用与结果、子代理派发、每次上下文注入），可完整重放。安装 `npx @deepseek-ai/dsh web`，默认 `127.0.0.1:3080`；MIT、TypeScript、2026-08-13 公开仓库、Web UI + macOS/Windows 桌面端；**developer preview**，运行前要求读 `SAFETY.md`。Creator Mode（2026-11-02 官宣）允许用自然语言生成可安装插件，官方 7 组演示（3D 建筑、Transformer 可视化、像素风界面、海报工作台、视频编辑、论文阅读器、会话统计），番茄钟插件从开发到安装验证约 **5 分 24 秒**；官方同时说明部分演示经过多轮对话调整，一条提示词不保证复现。
- **F-A7｜DSH Super-agent 原型（A 仓库 / C 报道，S37/S33/S36）**：2026-10-31 发布文章《Super-agent 设计探索》，同日开源 `deepseek-ai/dsh-superagent-prototype`（MIT），明确是**研究原型不是产品**。双层：常驻 **router**（统一接群聊/GitHub/邮件等多渠道、维护共享上下文、只做分派不深入执行）+ 上下文隔离并行的 **worker**（可再调 subagent，直接订阅后续消息，省去 router 转发）；事件驱动、存算分离（执行循环在云端、状态入库、本地只留轻量 daemon）、外部 **watchdog** 检查无效循环、异步 ReActLoop（尚未默认开启）、投机执行；两级过滤（程序规则快筛 + 模型语义慢判）后才行动，内部策略叫「静默复现并修复」。初步实验（**合成负载 + 简化环境，非产品结论**）：任务完成时间中位 **12.4 min**、P95 **15.7 min**；订阅直通为 router 省约 **37%** token；批处理把单次决定推理时间 **6.4 s → 1.6 s**。
- **F-A8｜Hermes 官方机制（A/B，S27/S28/S29；C 补充 S40/S11）**：Nous Research 出品、MIT，定位「内置学习闭环的自主 agent」而非 IDE 编码 copilot。核心：agent 自主管理记忆 + 定期 nudge、**从经验自主创建技能并在使用中自我改进**、FTS5 跨会话召回、Honcho 辩证用户建模；Skills 兼容 agentskills.io，可移植/分享/社区贡献，作为过程记忆复用。**15+ 消息平台网关**（Telegram / Discord / Slack / WhatsApp / Signal / Matrix / Mattermost / Email / SMS / 钉钉 / 飞书 / 企业微信 / BlueBubbles / Home Assistant 等）；**47 个内置工具**；**6 种终端后端**（local / Docker / SSH / Daytona / Singularity / Modal），空闲休眠（serverless persistence）；MCP 集成（可过滤工具）、内置 cron 定时自动化、profiles、ACP。官方仓库 `github.com/NousResearch/hermes-agent`，官方文档 `hermes-agent.nousresearch.com/docs`。掘金称其循环为 **TAOR + 状态机**（C，待官方文档核实）。
- **F-A9｜易变指标的处理**：DSH star 数在不同来源与日期分别为 15 万（公开数日内）、约 25 万（10 月中）、27.8 万（11-04）；OpenCode 官网自述 226,557；Hermes 站点自述 101K+，生态目录写 203,044（2026-11-12）。**相互矛盾且随时间变化**，课程正文不拿 star 数当能力论据；若提及必须写成「<日期> 快照，据 <来源>，仅反映社区热度」。
