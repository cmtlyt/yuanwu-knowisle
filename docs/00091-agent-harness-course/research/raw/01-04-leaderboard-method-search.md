Three Terminal-Bench tasks ask the agent to start a server, for example a model inference API, and the grader then tests that server after the agent has exited. What can you do if your server must outlive the agent? This section is our own analysis, not a claim from the board or its author. Given the confirmed behaviour, there are two sensible workarounds: Start long-lived services under systemd or with nohup and setsid, so they sit outside the agent's own process group and are not swept up at cleanup. State the persistence requirement explicitly in the prompt, for instance "leave the server running after you finish". We have not tested either against DSH, so treat them as a starting point and verify with a quick task before relying on them. Three attempts per task, every trajectory public. The premise is the question I keep arguing from the inside: hold the model still and let only the harness move, and see what moves. The Space asks you to log in to Hugging Face before showing a score, but the bucket behind it asks nothing, so I pulled the board’s own records and recomputed the table from them. All 45 harness cells check out internally — the macro scores are the mean of the per-benchmark rates, the confidence intervals bracket them, the declared ties are exactly the paired differences whose bootstrap intervals cover zero — and the totals are 28,849 trials for $4,746. I did not run any of the harnesses; every number below is the board’s, read from its records and recomputed, not from its UI. The first thing the numbers say is that the top is a tie. Across all models and efforts, the best five harnesses sit inside 2.2 points of each other — mini-swe-agent 51.4, Kimi Code 50.5, Hermes 50.3, Pi 49.4, Claude Code 49.2 — and none of the differences among them are statistically real. In the four flash-model cells, four or five of the nine harnesses are tied with the cell’s leader; on Flint, the weakest model, two manage it. Then a cliff: Qwen Code 44.7, Codex 44.5, OpenCode 35.5, OpenClaw 27.3, all measurably below. The board carries its own noise instrument, and it is the best thing on it. Three attempts per task let it compare how often re-running the same harness flips a task with how often swapping the harness does. On the flash models, re-running flips 24 to 28 percent of task outcomes; swapping harnesses flips 32 to 34 percent. On Flint, where scores are lower, both numbers roughly halve — 12 and 15 percent — and the ratio holds. Across all five cells the swap flips a task only 1.17 to 1.33 times as often as the dice do. At this tier, for the tied pack, the harness axis is barely larger than run-to-run noise; the harness effect is real but lives almost entirely in the bottom four. And the leader is not stable across cells: mini-swe-agent leads both flash models at low effort, Kimi Code leads GLM-5.3-Flash at high effort and Flint, Hermes leads DeepSeek-V4.1-Flash at high. “Which harness is best” has no answer; which harness is best for your model at your effort does, and the board is built to be read that way. What separates the tied pack is price. Cost per solved task, aggregated across the whole board: Pi $0.178, Claude Code $0.254, Hermes $0.283, mini-swe-agent $0.300, Kimi Code $0.308, and the three at the bottom — Codex $0.325, OpenClaw $0.684, OpenCode $0.904 — each pay more per solve than anything in the tie.
