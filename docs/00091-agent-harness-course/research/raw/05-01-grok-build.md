Grok Build is the terminal coding agent from SpaceXAI, the company behind the Grok models. Started with the grok command inside a project, it reads the codebase, edits files, runs shell commands, searches the web and tracks longer tasks in a full-screen terminal UI with mouse support. The same binary also runs headless for scripts and CI, and as an Agent Client Protocol (ACP) server for editors. The product page is x.ai/cli, and the online documentation starts at the Grok Build overview. The name also appears on a separate in-chat app builder in the Grok web and mobile apps; this listing covers only the terminal agent. SpaceXAI announced an early beta on May 25, 2026 for SuperGrok and X Premium Plus subscribers, published the source on July 15, 2026 and shipped version 1.0.0 on August 7, 2026. The official changelog lists 1.0.70, dated October 23, 2026, as the latest build at the time of checking; recent releases reworked the agent dashboard, made Vim navigation a single [keys] vim setting, let worktrees reuse saved approvals from the main checkout, and changed auto mode so a shell command runs without review only when every segment matches an allowlist entry. Releases arrive several times a week, so pin a version in automation. Prebuilt binaries are installed with curl -fsSL https://x.ai/cli/install.sh | bash on macOS, Linux and Git Bash, or irm https://x.ai/cli/install.ps1 | iex in Windows PowerShell. A WinGet package (xAI.GrokBuild) tracks the stable channel, and WSL receives the Linux binary. The installer accepts a specific version and a GROK_CHANNEL of stable, alpha or enterprise. There are no GitHub releases in the repository: binaries come from the x.ai installer. The xai-org/grok-build repository holds the Rust source of the CLI, the TUI and the agent runtime. It is synced periodically from an internal monorepo, and a SOURCE_REV file records the monorepo commit. Building from source needs the Rust toolchain pinned in rust-toolchain.toml (1.94.0 at the time of checking), DotSlash for the hermetic protoc, and macOS or Linux as the build host; Windows builds are described as best effort. The binary is named xai-grok-pager and official installs ship it as grok. First-party code is licensed under Apache-2.0, while vendored code, including ports of openai/codex and sst/opencode tool implementations and a Mermaid diagram stack, keeps its original licenses. The project does not accept external pull requests; the contribution policy describes the public tree as published for source transparency and local builds, and security reports go to the HackerOne program. Inference is not bundled: the default models are hosted by SpaceXAI and require a grok.com sign-in or an xAI API key, although custom models can point at OpenAI-compatible, Anthropic Messages or local Ollama endpoints.
