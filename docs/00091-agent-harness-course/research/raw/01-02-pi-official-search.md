History The origins of Pi trace back to Mario Zechner's experience with Claude Code, Anthropic's official command-line coding tool, which he began using in April 2025. Zechner was initially enthusiastic about Claude Code, crediting its team as genuinely talented, but grew frustrated as the tool's rapid feature additions introduced instability and unpredictable behavior changes. He wanted an AI harness that behaved in a stable, consistent way, and in August 2025 he created the pi-mono monorepo on GitHub under his badlogic username, establishing the foundational structure for what would become Pi using npm workspaces and TypeScript configurations. The post described how Pi deliberately omitted features that competing tools treated as essential, including built-in MCP support, sub-agents, plan modes, to-do lists, permission popups, and background shell execution.
