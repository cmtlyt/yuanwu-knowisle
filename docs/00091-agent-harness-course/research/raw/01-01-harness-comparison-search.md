## 4. [AI Coding Agents Compared: Which Harness Delivers the Best Success Rate?](https://code404zero.com/?p=502)

AI Coding Agents Compared: Which Harness Delivers the Best Success Rate?。One model, six different outcomes: with the identical AI called Kimi K3, the success rate across 26 identical coding tasks ranged from 17 to 21 solved tasks, and costs varied by a factor of 3.8. That is the central finding of a recent benchmark test by AI agent provider Composio, which pitted six coding harnesses against each other. Anyone searching for an AI coding agent comparison today usually ends up asking which model is best. The study shows the real question is which execution environment, the so-called harness, was built around that model. For developer teams working daily with autonomous coding assistants, this is an uncomfortable but valuable insight. Before expensively switching models, it is worth first looking at the framework that drives them. Table of Contents Key Takeaways With an identical model (Kimi K3), the success rate ranged from 17/26 (Codex) to 21/26 (Kimi Code), purely due to the harness. Cost per task ranged from $0.39 (Hermes Agent) to $1.47 (Claude Code), a factor of 3.7. Pi Agent was fastest at a median 161.7 seconds per task, while Claude Code at 347.6 seconds was more than twice as slow. Codex twice hit the 900-second time limit on a task that Pi Agent solved in 446 seconds. For tool selection: test a harness switch before considering expensive model upgrades. What Was Tested: The Composio Benchmark in Detail Provider Composio, which specializes in infrastructure for AI agents, published the comparison via an X thread. Six harnesses were tested: Kimi Code, Hermes Agent, Pi Agent, Claude Code, OpenCode, and Codex, each with the same underlying model, Kimi K3. All six combinations had to solve the same 26 agentic tasks: real, multi-step coding and automation workflows, including a complex expense-audit task with multiple intermediate steps. The methodological core matters here: the model stayed constant. Only the software layer that gives the model tools, file access, and terminal permissions differed. This isolates the effect of the harness without model differences distorting the result. It is exactly this controlled test setup that makes the Composio comparison so informative for a well-founded AI coding agent comparison. First: the success-rate leader, Kimi Code, is neither the cheapest nor the most expensive harness. Anyone choosing purely on name recognition might end up with the worse choice for their own use case. What Is a Harness? An Explanation for Beginners Anyone who doesn’t work with agent architectures daily quickly stumbles over the term. A harness is, at its core, the software environment that connects an AI language model to the real work environment. The model itself, say Kimi K3, can only generate text. It doesn’t automatically know how to open a file, run a terminal command, or test a code change. That’s exactly where the harness comes in. It provides the model with tools, such as: File access for reading and writing code Terminal commands for running scripts Memory and context management across multiple steps Error handling when a step fails Rules for when a task counts as complete So two harnesses can use the same model and still work completely differently, depending on how efficiently they plan intermediate steps, how sparingly they use tokens, and how robustly they handle errors. That’s exactly why an AI coding agent comparison should never be just a model question, but always also a question of execution architecture. Why the Harness Matters More Than the Model The core message of the Composio study can be summarized like this: before teams switch models to cut costs or improve reliability, they should first test a different harness.
