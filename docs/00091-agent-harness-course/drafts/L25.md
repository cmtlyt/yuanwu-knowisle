### 交叉读法一：头部并列，别排座次

头部五家落在 **2.2 分内互不显著**——榜单作者的结论值得原样引用：*「哪个 harness 最好」无解，「哪个 harness 对你的模型 × effort 最好」才有解*。任何「2026 最强 harness 排行榜」如果把这五家排出 1-5 名，都是在给噪声排序。真正的结构信息在**断层**：头部并列组之后是 Qwen/Codex 的中游带（44.5–44.7），再之后是 OpenCode/OpenClaw 的显著落后区（35.5/27.3）——**改进空间几乎全在断层之下**，选择头部五家中的任何一个都不会因为「选错 harness」而掉队。

### 交叉读法二：成本必须三口径对齐

同一个 harness 的「成本」在三套口径下可以差出 5 倍（OpenCode：$0.904 聚合 vs $3.35 公告）。正确读法是**先问计算者与分母**：

```text
成本读数三步（L02 四问③的展开）
① 分母是什么？   per run（全部 trial）/ per solved task（解出的）/ per solved trial
② 谁算的？       榜单公告口径（按模型先平均）/ 独立复算者（全盘聚合）/ Composio 自算
③ 排除离群值了吗？ 公告口径的 11.7× 极差主要由 Flint 7% 解决率拉大；
                   剔除 Flint 后头部组的成本差异远小于表面数字
```

交叉后**方向一致**的结论才可信：Pi「便宜快」在 Bug Hunt（三档最便宜）、Composio（最快 + $0.40）、聚合口径（$0.178 最低）三处一致；Hermes 的「便宜快」在 Composio（$0.39/180s）成立；OpenCode 的「贵 + 分低」在聚合/公告/榜单三处一致。而「谁是最贵的」这类单点结论，换一个口径就翻转——Claude Code 在 Composio 里最贵（$1.47），但 Bug Hunt 里它只是中游（$0.254 聚合）。

### 交叉读法三：伪影案例的三张面孔

四套数据贡献了三个教科书级伪影案例，分别对应三种机制：**配置伪影**（OpenClaw 8192-token 上限终止 289/333 trials，末位分数部分由默认值写出，解除后重跑中）；**超时伪影**（Codex 两次撞 900s 上限，同任务 Pi 446s 解出）；**环境伪影**（FeatureBench 全员 77% 读答案，修复后 62.9%→7.9%）。三张面孔的共同教训：**看到异常分数，先查 harness 配置与实验环境，再谈能力**。

### 交叉读法四：model×harness 交互的三个数字

arXiv 论文给横向读法补了时间维度：**秩相关 0.36**（两模型下 harness 排名只有弱延续）、**+7.94 ↔ −30.16**（Claude 在 OpenHands/Pi 下的对 GPT 翻转）、**稳定配对的存在**（openJiuwen 给 Kimi 三基准最高 +5.61~+11.11）。加上论文的机制解释（失败交回形式决定成败——GPT 适合 Pi 的精简 scaffold、常发 malformed tool calls 的 Kimi 适合 openJiuwen），选型操作的结论是：**在你自己的模型 × 你的任务域上跑 pilot，比读任何排行榜都有效**；榜单的用法是「排除明显断裂的底部」与「发现值得试的稳定配对」，不是「选第一名」。

### 追问与辨析：亲手复算两种聚合口径

F-B4 的口径冲突最适合当练习题：S04 作者按**全盘聚合**复算的 cost per solved task（Pi $0.178 / Claude Code $0.254 / Hermes $0.283 / mini-swe-agent $0.300 / Kimi Code $0.308），与榜单公告按**模型先平均**的口径（Pi $0.29 / mini-swe-agent $0.53 / Claude Code $0.52 / Kimi Code $0.63 / Hermes $0.65）来自**同一批 28,849 条记录**，差别只在聚合顺序——两组数字都能自洽，任何一张混合它们的表都是错的。复算方法：榜单公开全部 trajectory 与外部计量代理的成本记录（F-B1），拿原始记录自己按两种顺序各算一遍，再观察并列组内 1.7 倍的极差从哪里来。这个练习的价值在于把「证据分级」从口号变成肌肉记忆：**引用任何基准数字前，先问聚合口径**。

```python
# 同一批记录、两种聚合顺序（数字引自榜单公告与 S04 作者复算，F-B4；单位 $/solved task）
full_pool = {"Pi": 0.178, "Claude Code": 0.254, "Hermes": 0.283,
             "mini-swe-agent": 0.300, "Kimi Code": 0.308}      # 全盘聚合（S04 复算）
per_model = {"Pi": 0.29, "mini-swe-agent": 0.53, "Claude Code": 0.52,
             "Kimi Code": 0.63, "Hermes": 0.65}                # 按模型先平均（公告口径）
# 观察点：Pi 在两种口径下都最便宜；mini-swe 与 Claude Code 的相对位置被聚合顺序改变
# 教学结论：两组都「对」——引用时不声明口径即视为错误引用
```
