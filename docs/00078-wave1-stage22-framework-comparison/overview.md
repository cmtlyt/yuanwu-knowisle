重写模块七的收束阶段（4 课）。这一批不是「再讲一个框架」，而是把前面六框架（LangGraph / OpenAI Agents /

## 术语统一

- **对比维度**：能力 / 成本 / 可控性 / 学习曲线 / 运行时位置 / 抽象层数 / 默认哲学。
- **薄封装 vs 重抽象**：薄封装无隐式状态可单独替换；重抽象接管控制流、迁移成本高。
- **回退手写**：不是删光框架，是「保留薄封装、弃掉重抽象、把控制流拿回自己手里」。
- **跨语言借鉴**：取架构思想（角色 / 群聊 / 规划），在目标语言重实现，不引 Python 依赖。

## 变更计划

1. L112：以「选框架只看谁最火」开场；给六维度矩阵表 + 一个生成矩阵的 `compare()` harness（代码达标）；讲「矩阵是起点不是终审」。
2. L113：给「框架在拖后腿」的五个信号 + 薄封装/重抽象边界 + 三步迁移策略（先留薄封装→再抽控制流→最后弃重抽象）。
3. L114：用四框架各写同一个「天气查询 + 工具调用」Agent，给维度对照与「只比代码量」的陷阱。
4. L115：讲 AutoGen 群聊 / CrewAI 角色编排的架构思想，用 TS 各复现一个最小示例（不写 Python）；讲「取思想不取依赖」。
5. 每节 ≥1 表格、≥2 callout、≥1 代码块（L113 代码≥400）；双扫描；`--update-baseline`；全门禁。
