# Wave 1 第二十一批：Stage 23 场景纵深四课（L117–L120）

## 目标

重写模块八的四个垂直场景（4 课，全部 `scenario`）。这一批的风险是「把前面组件拼一遍」——数据 Agent 讲一遍 RAG、研究 Agent 再讲一遍 RAG、GUI 讲一遍工具调用、语音讲一遍流式，四课相互重复且没有新增认知。

统一定位：**每个场景都有一个「不可退让的约束」，这一约束决定了整条流水线怎么搭**。四课的约束分别是：

| 课 | 场景 | 不可退让的约束 | 它如何反向决定架构 |
|---|---|---|---|
| L117 | 数据 Agent | 不可写 + 口径唯一 | 语义层先于 SQL、只读账号 + 白名单 + 结果校验 |
| L118 | 研究 Agent | 每条结论可溯源 | 引用 id 随文本一起流动、生成后做溯源校验而非生成前堆料 |
| L119 | GUI Agent | 动作后必须验状态 | 观察—动作—再观察闭环、弹窗/异步态不能靠猜 |
| L120 | 语音 Agent | 端到端时延预算 | 全链路流式、VAD 与 barge-in、按预算倒推每段允许耗时 |

按 00055 下限：scenario = 正文 **1800 字** / 代码 **1500 字符**；余量 >50；每课 ≥1 表格、≥2 独立 `:::deep` / `:::warn` callout、≥1 可运行代码块。

## 术语统一

- **语义层（semantic layer）**：把「销售额」「活跃用户」等业务口径固化成带版本的定义，模型选口径而不是自由拼 SQL。
- **引用绑定（citation binding）**：每个检索片段携带稳定 id，生成时随文本一起进入上下文，生成后按 id 回查。
- **观察—动作闭环**：GUI 里每次动作后必须重新取一次界面快照再决定下一步，不得用「上一步应该成功了」当状态。
- **barge-in**：用户说话时打断正在播放的 TTS，需要取消传播到 TTS 与 LLM 两边。
- **时延预算**：从用户停止说话到第一个音频字节的目标，按段拆分并给每段上限。

## 变更计划

1. L117：以「一句『上季度各区域销售额』把退款单算进去、报表多 12%」开场；给语义层 + SQL 生成器 + 只读/白名/结果校验三段可运行代码；讲「口径错了比 SQL 错了更危险」；给错数验收清单。

3. L119：以「确认框上连点两次删了两条」开场；给可访问性树快照 → 动作空间 → 动作后状态断言的最小闭环；讲异步/弹窗/乐观更新的三类陷阱。

5. 每课末尾单列「与相邻课的分工」。
6. 双扫描（`tmp-backtick.mjs` + `tmp-escape.mjs`）、渲染抽查、`--update-baseline`、`pnpm verify` / `lint` / `typecheck`。

### 实际写出的可运行物

- **L117**：语义层 \`METRICS\` 定义 + \`renderMetric()\` 参数化渲染器（模型只产 metricId/dim/range）、\`assertSafeSql()\` + \`safeExec()\` 六道执行闸、金标准回归 \`runGoldenCase()\`（口径选择 / SQL 安全 / 数值误差三条断言）。主结论：**口径比 SQL 危险，安全边界和正确性边界是两条轴**。
- **L118**：\`packEvidence()\` 带 sid 的片段结构、两阶段生成（\`buildFactCards()\` → \`composeReport()\`）、\`verifyCitations()\` 按句校验器（no-citation / orphan-id / anchor-mismatch 三类）、接进 L81 的溯源断言。主结论：**溯源靠生成后的校验器；综合会破坏归属，所以先分后合**。
- **L119**：\`observe()\` 可访问性树快照（含 \`entityId\`）、\`step()\` 观察—动作—再观察 + 状态差 \`expect\`/\`forbidden\`、\`waitStable()\` 连续两次快照一致、模态守卫、假界面闭环验收。主结论：**点击只是发出意图，观察₂ 是唯一能证明生效的证据；断言失败停机不重试**。
- **L120**：\`BUDGET\` + \`LatencyMeter\` 分段打点、\`speakTurn()\` 全链路流式级联（ASR partial 起 LLM / 按标点切句 / TTS 分块）、\`onUserSpeech()\` barge-in 取消传播四级、时延回归断言。主结论：**预算对象是首字节而非总时长；打断要取消到最上游**。

### 过程中发现并修掉的坑

写 L117 时代码块里的 SQL 过滤条件用了 \`'status = \\'PAID\\''\`，\`\\'\` 在 TS 模板串里是合法转义、直接输出 \`'\`，渲染后变成非法的 \`'status = 'PAID''\`。**esbuild / lint / typecheck / 两个临时扫描脚本全部不报错**——\`tmp-backtick.mjs\` 只查反引号、\`tmp-escape.mjs\` 只查 \`\\d\\b\\s\\w\\n\\t\`，都不覆盖 \`\\'\`。修法是外层改双引号 \`"status = 'PAID'"\`，并用 \`npx tsx -e\` 导入课文件**打印渲染后的 md 文本**核对代码块是否仍是合法代码。已按 pitfall-resolver 闭环回写到 \`references/course-content.md\` 的「正文渲染」表，新增一行（第三种模板串转义）。

另两处初稿未过线：L118 正文 1675、L119 1612、L120 1775，均补的是 goals 里承诺但未展开的实质节（深度研究 vs RAG 对照表 + 溯源率度量口径 / CV 依赖边界 + 人工交接 / 降级阶梯 + 预算校准），不是灌水。
