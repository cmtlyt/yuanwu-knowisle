## 术语统一（Stage 5–8 共用）

- **运行时（runtime）**：把「模型决策 → 动作执行 → 观测回填」推进下去的那层代码；与「Agent 框架」
  不同，前者是机制，后者是打包。
- **工具（tool）** / **函数调用（function calling）**：前者是能力，后者是模型侧的调用协议；
  混用会导致「工具有问题」和「模型不会调工具」两种故障被归到同一类。
- **Schema 是契约**：工具描述的质量直接决定调用成功率，它是工程资产而不是注释。
- **记忆（memory）** 分三层——工作记忆（上下文内）、情景记忆（可检索的历史轨迹）、
  语义记忆（结构化事实）。三者的写入时机与淘汰策略不同。
- **推理增强**不是「让模型更聪明」，而是「用更多 token 换更深步骤」；它的收益随任务复杂度变化，
  单步任务上通常为负。
