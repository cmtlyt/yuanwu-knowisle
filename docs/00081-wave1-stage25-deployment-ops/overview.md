## 术语统一

- **状态外置**：会话状态存到实例之外的共享存储，实例本身无状态。
- **租约（lease）**：带过期时间的会话所有权，防止两个实例同时推进同一会话。
- **降级阶梯**：按代价从低到高逐级切换，且每级本轮生效、可回退。
- **影子流量**：复制真实请求到新版本但不返回其响应，用于无风险对比。
- **容量模型**：\`L = λ × W\`（并发数 = 到达率 × 单请求占用时长），L92 的结论在这里用于算实例数。
- **runbook**：把故障处置写成可执行、可演练、可验收的步骤。

## 变更计划

1. L123：以「加了两台实例后同一会话的两条消息分别落到不同实例、上下文丢了一半」开场；给状态外置 + 租约 + 幂等写入 + 会话亲和对照表；讲「粘性会话只是把问题推迟」。
2. L124：以「一个工具超时 30s，重试 × 排队把线程池吃满」开场；给超时预算 / 熔断 / 降级阶梯 / 兜底响应；讲「重试是放大器」（复用 L92 的 \`λ×W\` 结论，不重推公式）。
3. L125：以「灰度 5% 看着正常，全量后 p95 翻三倍」开场；给按租户/会话分桶的灰度路由 + 影子流量 + 容量模型 + 回滚判据；讲「按请求随机分桶会把同一会话切裂」。
4. L126：以「凭证过期后所有长任务同时失败，却没人知道该找谁」开场；给版本迁移矩阵、凭证轮换、数据留存与删除、runbook 自检脚本；讲「运维的对象是契约，不是服务器」。
5. L127：综合实战，给一个服务骨架（状态外置 + 降级 + 灰度 + 健康检查）、三类告警规则（业务 / 时延 / 成本）与一次演练脚本；验收断言覆盖前四课各一条。
6. 每课末尾单列「与相邻课的分工」；不新增 concepts id（五个 id 均已注册）。
7. 双扫描、渲染抽查、`--update-baseline`、三门禁。
