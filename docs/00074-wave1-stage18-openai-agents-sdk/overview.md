## 术语统一（Stage 18 共用）

- **进程内形态**：`run()` 是一次函数调用，无 super-step、无快照。与 LangGraph 的有状态执行机相对。
- **交出控制权**：handoff 的本质不是调用函数，而是把对话交给另一个 agent 继续。
- **接管一半**：框架接管循环与消息装配，不接管取消传播、单次工具超时、断点续跑。
- **三点零转移**：控制权点对点转移，回退只能靠显式反向边。
- **改写 / 判断 / 拦截**：三件不同的事，分别放在入口层、护栏、调用方。
- **关机测试**：假设护栏全部失效会不会出事故；会则说明把权限问题错当护栏问题。

### 与原变更计划的偏差

1. **L101 增加「把 SDK 版包成 L94 的 Impl」一节**：原计划只做结构对照。实测认为框架课必须有
   可纳入同一把尺子的适配器，否则「度量差异」永远停在定性描述。
2. **L101 补「互转熔断计数必须放 run context」**：这是并发场景下共享可变状态的复发坑（L92），
   且表现为「模型变笨」的假象，值得单列。
3. **L102 把「改写 / 判断 / 拦截」提为独立小节**：原计划只写「声明式 vs 手写」。实测认为
   误拦 8% 的根因不是规则写得差，而是**把改写做成了拦截**，这个分层比工具选型更本质。
4. **L102 补「工具参数层」护栏位置**：声明式框架通常只有输入/输出两个钩子，而生产里最贵的
   是中间层（L85 的授权点）。这一层没有框架支持，必须手写，所以显式列出来。
5. **修正一处历史遗留的转义 bug（跨批次）**：本批 lint 报出 `no-useless-escape`，根因是模板串
   内代码块的 `\d` `\b` `\s` 被 JS 当转义处理（`\d`→`d`、`\b`→退格符，课程页面显示错误代码）。
   写 `tmp-escape.mjs` 全量扫描，共发现 **5 处**：本批 L102 的 5 行正则，以及历史遗留的
   `l47`（行内代码 `` `OK\n…` ``）与 `l82`（`join('\n')`、`SYS + '\n\n'` 共 4 行）。
   全部改为双反斜杠后复查渲染。**这类 bug lint 只覆盖 `\d \b \s \w`，`\n \t` 不报但静默破坏
   渲染**，因此脚本化扫描是唯一可靠手段。已回写 `pitfall-resolver/references/course-content.md`。
