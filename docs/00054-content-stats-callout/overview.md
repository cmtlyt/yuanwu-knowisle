# 00054 · `contentStats` 口径修正：提示框正文计入 + 闸门指标改字数

## 目标

两个口子要一起堵——否则「体量够不够」这件事既不诚实也不可比：

1. **容器正文漏统计**：`contentStats(md)` 在剥离 `:::deep / :::warn / :::tip` 容器时，**把容器内的正文一并丢弃**，导致「用户实际要读的字」有近一半不计入 `proseChars`。
2. **字符数当字数用**：闸门阈值写的是「正文 1200 字」，量的却是 `proseChars`（字符数，含标点、段间空格、英文按字母），比实际字数虚高约 1.58 倍，而且能靠堆标点 / 拉长标识符刷量。

用户两轮提问依次发起：「prose 是否会包含 code 的内容？看起来文章还是偏短啊」→「prose 统计的应该是字符数不是字数吧，字符数的话会不会包含很多的 md 结构字符？」。

`prose` **不含** code 是有意设计（code 另计 `codeChars`），这一条不改；**不含 callout 正文**、**字符数冒充字数**这两个是缺陷。

## 现状（实测 142 节 Agent 课）

| 项 | 数值 | 均值/课 |
|---|---|---|
| 当前 `proseChars` 合计 | 39,125 | 276 字符 |
| callout 容器内正文合计 | 30,837 | 217 字符 |
| **漏统计占比** | **+78.8%** | — |
| `codeChars` 合计 | 63,265 | 446 字符 |

典型课（`prose` 几乎只剩导语，主体全在容器里）：

| 课 | 课型 | 当前 prose | callout 正文 | 合计 |
|---|---|---|---|---|
| L13 ReAct 实现 | theory | 64 | 297 | 361 |
| L37 流式输出 | practice | 202 | 330 | 532 |
| L95 | framework | 186 | 286 | 472 |

L13 的 `:::deep`（LangGraph 的 ReAct 对照）与 `:::warn`（maxSteps 的必要性）都是实打实的叙述内容，不是装饰性提示框——按现在的口径它们对体量检查完全隐形。

## 根因

`app/lib/markdown-md.ts` 的 `contentStats`：

```ts
prose = prose.replace(/:::[\w-]+\n[\s\S]*?:::/g, () => {
  callouts++      // 只数个数
  return ''       // 正文被整体丢弃
})
```

`ContentStats.proseChars` 的注释写着「去除代码 / 容器 / 标记语法后的纯文本」——「容器」二字说明当初**有意**排除。这个判断在「callout 只是零星提示框」的假设下成立；实测 78.8% 说明假设不成立：00051 批量生成时把「框架对照」「注意事项」「深度补充」这些都写成了容器，容器承载的是主体叙述。

## 变更计划

**阶段一 · 容器正文**

1. `app/lib/markdown-md.ts` / `contentStats`：容器**脱壳保留正文**（`return body`），仍累加 `callouts` 计数；容器内 `### 标题` 随正文一起计入 `headings`。
2. `scripts/content-gate.mjs`：判定逻辑不动，重跑 `--update-baseline`，L11 / L79 / L93 因正文补齐到 250 字以上达标而退出豁免名单。

**阶段二 · 指标从字符数换成字数**

3. `contentStats` 顺手清掉残留的 md 结构记号：有序列表序号 `1.`、表格管道 `|` 与分隔行 `|---|`（原先都留在 `proseChars` 里）；链接 `[文字](url)` 改为**保留可见文字**（原实现把整段删掉，连文字一起丢，属于少算）。`proseChars` / `proseWords` 两条字段注释写明各自量什么。
4. `scripts/content-gate.mjs`：`THRESHOLDS` 的 `proseMin` → `wordsMin`，判定改用 `stats.proseWords`，报错与表格文案统一成「正文字数」。
5. `app/lib/lesson-time.ts`：时长**继续**按 `proseChars` 算（标点也占停顿），但把「为什么闸门用字数、时长用字符数」写进 `TIME_RATES.prosePerChar` 注释。
6. `scripts/verify-content-stats.mjs`：补 4 条断言（表格管道、有序列表、链接、标题/bullet），把「md 结构不能计入正文量」钉住。
7. `docs/README.md` 加本任务索引行；`.workbuddy/skills/course-builder/references/data-model.md` 同步口径。
8. `docs/00052-agent-course-rebuild/overview.md` **不改**（历史记录不可矫正约定）；其 prose 数字、「7/142 达标」与 800/1200/… 阈值在新口径下已失效，以本记录为准。

## 阶段一影响（实测）

| 项 | 修复前 | 修复后 |
|---|---|---|
| 正文达标（`proseChars` ≥ 旧 `proseMin`） | 7/142 | **10/142**（+L11/L79/L93，均为 overview） |
| 正文量均值（practice 62 课，字符数） | 217 | **412** |
| 正文量均值（capstone 15 课，字符数） | 505 | **788** |
| 全课总时长 | 1,391 min | **1,490 min**（+7%，均值 9.8 → 10.5） |
| 试点 6 课时长 | 18/29/20/29/33/31 | 19/31/22/31/35/33 |

**不会掩盖稀薄**：修复后 62 节 practice 课均值 263 字（字符数 412，字数下限 750），132 节课仍在豁免名单里。这次改的是「数字是否诚实」，不是「降低门槛」——顺带说明：修复后阈值实际变得更宽松（同一段内容原先不计，现在计），但达标数只从 7 涨到 10，说明薄是真薄。

## 阶段二：字符数 → 字数

**为什么必须换**。142 课合计 `proseChars` 69,933、`proseWords` 44,331，比值 **1.58**。拆开看：

| 组成 | 数量 | 占 `proseChars` |
|---|---|---|
| 汉字 | 41,526 | 59% |
| 英文字母（标识符、术语） | 13,949 | 20% |
| 标点 | 9,017 | 13% |
| 段间 / 词间空格 | 5,441 | 8% |
| md 结构残留（表格管道 + 有序列表序号） | 311 | 0.4% |

也就是说「1200 字符」实际只有约 760 字。md 结构残留经阶段二清理后只剩 0.4%（原本也不多），真正的虚高来自**标点 13% + 空格 8% + 英文按字母 20%**。字符数还有个更糟的性质：**能被无成本刷高**——多打标点、多插空行、把 `useEffect` 展开成 `useEffectEveryRender` 都能推高数字。

**阈值折算**。按比值 1.58 折算成整数，保持同一严格度：

| 课型 | 旧（字符） | 新（字数） |
|---|---|---|
| `theory` | 800 | **500** |
| `practice` | 1200 | **750** |
| `framework` | 1000 | **650** |
| `scenario` | 1200 | **750** |
| `capstone` | 2000 | **1250** |
| `overview` | 400 | **250** |

**折算是否可信**：在新口径下重跑，达标名单是 `L01 L11 L26 L42 L79 L93 L96 L116 L128 L135`——与旧口径**完全同一批 10 节，一个不多一个不少**。这说明折算不是为了让结果好看而凑参数，而是两种度量对同一批课给出了相同判断。

**时长口径为什么不动**：`TIME_RATES.prosePerChar` 是 1/320 分钟/字符，折合约 200 汉字/分钟。技术叙述需要停下来理解，200 字/分钟是合理值；若改成按字数算，同一批课时长会再降 37%（试点 L42 从 31 分钟掉到 20 分钟），反而失真。所以**闸门量字数（可复核、防刷），时长量字符数（含标点停顿）**，两条口径各自服务于不同问题。

## 验证方案

1. 口径自检 `scripts/verify-content-stats.mjs`：10 条边界断言（容器正文计入 / 容器内代码只计 codeChars / 标题计入 / 表格管道与有序列表不计 / 链接保留文字 / fence 的 title-note 不计）+ 194 课真实抽样。
2. `node --experimental-strip-types scripts/content-gate.mjs --verbose`：确认 10/142 达标、豁免 132（与旧口径同一批课）。
3. `pnpm verify` / `fmt:check` / `lint` / `typecheck` / `build` 全绿。
4. 起 Worker 预览抽查课时页时长与地图页总时长是否同步（`lessonMinutes` 与闸门共用同一入口，不会漂移）。
