## 术语统一

- **默认行为**：SDK 未经显式配置就替你决定的超时、重试、错误结构等，是「同一段代码两次不一样」的常见来源。
- **范式**：Agent 循环「怎么转」的可复用套路，不是框架、不是提示词模板。
- **四维矩阵**：上下文成本 / 可靠性 / 可控性 / 典型场景，用来筛范式而非排榜。
- **分层混合**：P&E 做骨架、ReAct 做单步、Reflexion 做失败后纠错，各自有触发条件与预算，不是三个 prompt 拼一起。
