# 00095 · pitfall-resolver references 精简（00094 续）

## 目标

00094 精简了 SKILL.md（17,353 → 4,158 字节）与 description，用户追加要求「参考文件也需要进行一定程度优化」。references 合计约 99 KB，虽按需读取，但单次命中大文件（如 `course-content.md` 34 KB）仍会把整节长表格塞进上下文。目标：**压缩叙述性用词、合并同类条目、缩短表格单元格**，同时保证每条实测结论（症状 / 根因 / 处理）与全部错误原文、命令、版本号零丢失。

## 变更计划

1. 对 9 个 `references/*.md` 逐个精简，保留全部 4 类关键信息：① 症状原文（报错文本、命令名、版本号）；② 根因；③ 已实测处理（可直接复制的命令 / 判据）；④ 历史修正说明（旧结论标「不适用」时保留一句）。
2. 具体手法：
   - 表格单元格中的长叙述压成短句，删除「本例 / 实测 / 不要忘记」等口头衬词，但保留实测日期归属（节标题里一次注明）；
   - 同一根因的多条症状合并为一行，症状原文用 `、` 并列，不删任何一种报错文本；
   - Markdown 列表的粗体标签统一缩短（`- **触发症状**：` → `- 症状：` 等），空行只留段落间一处；
   - 重复的「验证命令 + 预期退出码」在同一节里只写一次，跨节不重复时保留。
3. **不删除任何条目**，不新增知识；只改变表达密度。按 §1 闭环回写：在 `toolchain.md` 的「skill 文档自身占用上下文」条目里补一句「references 精简按知识零丢失校验」，本 overview 登记完整变更。
4. 更新 `docs/README.md` 索引与当日日志。
