# Wave 1 第十四批：Stage 16 框架生态总览与对照方法论（L93–L95）

## 目标

重写模块七的入口三课：**先给选型维度，再给对照方法，最后给工程骨架**。这三课本身不讲任何
具体框架的实现细节（那是 L96–L115 的事），它们要解决的是「读者凭什么相信后面那些结论」。

## 术语统一（Stage 16 与模块七共用）

- **运行时位置（runtime locus）**：你的 Agent 的「运行」活在哪——进程内库 / 托管服务 /
  图解释器 + 状态存储。它决定部署形态，比 API 好不好看重要一个量级。
- **对照实验（paired comparison）**：同一需求、同一模型、同一工具集、同一评测集，
  只换编排层。任一项没锁死，结论就不可信。
- **胶水代码（glue code）**：把业务语义翻译成框架概念的那部分代码。它是框架的真实成本，
  但经常被算进「框架让代码更少」的账里。
- **抽象泄漏（leaky abstraction）**：框架内部细节渗透到使用方，让你为了绕开它而写更脏的代码。
- **版本锁定**：lockfile + 精确版本 + engine 约束三重锁；只写 `^` 不算锁定。

## 变更计划

1. L93：四维度各自给出「判据问题」，把「运行时位置」拆成三种形态并列部署影响；给六框架
   的初步定位表**并显式声明结论绑定版本**；说明框架还的三类债（编排表达 / 生态集成 / 运维）。
2. L94：讲对照组设计（五个必须锁死的变量）、五个度量维度与各自的造假方式、三个污染源；
   给一个可运行的对照 harness（统一 `Impl` 契约 + 超时 + 多次重复取通过率）。
3. L95：给版本锁定表口径与三个常见破口；给框架无关目录结构、核心接口
   （`LlmClient` / `Tool` / `AgentRun` / `Trace`）与一个确定性 `FakeLlm`，让对照能在无网络下跑。
4. 每节 ≥1 表格、≥2 独立 callout；L94 / L95 各 ≥1 可运行代码块；渲染抽查；全门禁。

### 每课的开场事故与核心论证

| 课 | 开场事故 | 核心论证 |
|---|---|---|
| L93 | 选 star 最多的框架，上线前一周发现它的运行时需要长驻进程 + 本地 checkpoint，与 serverless 不兼容 | 四维度 + 运行时位置三形态（进程内库 / 图解释器 + store / 托管服务）+「三笔债」判该不该引框架 |
| L94 | 四框架横评结论三个月后被推翻：需求被无意识裁剪、评测集照着参照实现写 | 五个必须锁死的变量 + 五维度量与各自造假方式 + 首分歧归因表 + 「做不到清单」才是判决 |
| L95 | 对照仓库放一个季度，回来三个框架装不上了（peer 冲突 / engines 不满足 / 大版本 API 全变） | 四重锁（lockfile / 精确版本 / 运行时约束 / peer 区间）+ core 零依赖 + FakeLlm 分离编排与质量 |

### 与原变更计划的偏差

1. **L93 增加了「三笔债」判据**：原计划只有四维度，实测发现「四个维度都合格但仍不该引框架」
   的情形很常见（只需要生态集成时），因此补了「编排表达 / 生态集成 / 运行时运维 欠几笔」这条
   可数的判据。
2. **L93 的六框架定位表显式声明「绑定版本」**：原计划直接列表，实测认为这会诱导读者把结论
   当常量背下来，因此改为「先记维度、再记结论」，并在 L95 用四重锁收口。
3. **L94 把「改动成本」提为 LOC 的替代指标**：原计划的度量维度里只有「代码量」。实测认为
   LOC 可被配置化/默认值/删错误处理三种方式做低，因此补了改动成本（同一批变更触碰的文件数、
   是否需读框架源码），并给出一条经验数字：**LOC 差 <30% 时改动成本可差 3 倍**。
4. **L94 增加「首分歧」工具**：原计划只有度量，没有归因。实测发现「通过率不同」无法支撑任何
   决策，必须能定位到哪一步分歧、并判断是规格问题还是框架默认行为，因此补了
   `firstDivergence` 与四分表。
5. **L95 增加 FakeLlm**：原计划只写接口与目录结构。实测认为不隔离模型噪声，对照实验的方差
   会让一切度量失效，因此补了脚本化确定性模型，并说明「先验编排、再验质量」的两段式。

### 课型复核结论

三节原标注全部正确，未发生课型纠正。L93 是 overview（无实现、交付对照表与判据）；
L94 交付可运行的 harness 与归因工具，L95 交付可编译的工程骨架与接口定义，均属 framework。
