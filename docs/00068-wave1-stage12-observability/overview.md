## 术语统一（Stage 12 共用）

- **三支柱**：日志（离散事件，带上下文）、指标（聚合数值）、追踪（因果链）。三者不是替代关系，
  分别回答「发生了什么」「现在多少」「为什么慢/为什么错」。
- **span**：一段有起止时间的操作，是追踪的原子单位。必须带 `name`、`start/end`、`status`、
  以及**足够定位的属性**（模型名、工具名、token 数）。
- **trace**：同一个因果链上所有 span 的集合，由 `traceId` 关联；`parentSpanId` 决定树形结构。
- **采样（sampling）**：只保留部分 trace 的策略；Agent 场景下「错误全采 + 成功按比例采」通常优于
  均匀采样。
- **回放（replay）**：用记录下来的输入序列重跑，使非确定性的 Agent 产生可复现的现场。与「重试」
  的区别是：重试接受不同的输入（新的模型输出），回放固定输入。

## 变更计划

1. L72：给一张「Agent 该观测什么」的指标表（每步延迟、工具错误率、token 分布、终止原因、
   重试次数），讲清为什么「平均延迟」在 Agent 里几乎无用（长尾由单步最慢决定），以及采样策略。
2. L73：给 span 的最小必要属性集、父子关系如何表达工具调用与模型调用、跨进程/跨 Agent 的
   `traceId` 传播，以及「一次请求穿过多少工具」这个具体问题的回答方式。
3. L74：讲两种回放——确定性回放（录制模型输出、固定种子）与记录即回放（只读轨迹重建现场），
   给「哪些东西必须录」的清单与「回放不一致」的排查顺序。
4. L75：手写 Tracer / Span / Context 三个抽象，实现一个可运行的 span 中间件（含嵌套、错误标记、
   属性收集、导出），对照 OpenTelemetry SDK 与 LangSmith 的等价埋点。
5. L76：把中间件接进 L68 的 MessageBus，实现跨角色 trace 串联、群聊场景的树形结构、以及基于
   轨迹的回放器。
6. 每节 ≥1 表格、≥2 独立 callout、≥1 可运行代码块；渲染抽查；`--update-baseline`；全门禁。
